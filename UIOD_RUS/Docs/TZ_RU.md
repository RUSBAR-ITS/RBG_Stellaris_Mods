## 1. Назначение

Создать отдельный мод с ID `UIOD_RUS` и отображаемым именем `UI Overhaul Dynamic - Russian Localization Fix`, который переводит оставшиеся английские строки UI Overhaul Dynamic и UI Overhaul Dynamic - Ascension Slots при выбранном русском языке игры. Имя уточнено по прямому поручению пользователя; ID, имя каталога и имя файла подключения остаются прежними.

Установленная игра: Stellaris Cygnus v4.5.4 (1b4f), по `launcher-settings.json`. В манифесте и файле подключения указать `supported_version="v4.5.*"`: префикс `v` обязателен по уточнению пользователя. Начальная версия мода: `0.0.1`; версия после изменения имени: `0.0.2`; версия после исправления формата `supported_version`: `0.0.3`.

## 2. Объём работы

Перевести 19 существующих ключей: 12 из основного UIOD и 7 из Ascension Slots. Это 18 явно непереведённых строк из аудита плюс подпись `Steam Workshop`, которая переводится как «Мастерская Steam».

More Tradition Categories (80), Tiny Options и Tiny Outliner не добавляют собственных файлов локализации. Их ванильные ключи и исходные заготовки в GUI не изменяются.

Названия UI Overhaul Dynamic, UI Overhaul Dynamic - Ascension Slots, Gigastructural Engineering, Stellaris, Discord, Steam, Paradox Interactive, GitHub, имя Xelnath и аббревиатура EHOF сохраняются как собственные имена. Имеющиеся русские переводы, числа и строки только с подстановками не переписываются.

Сломанная ссылка `UIO_FAVORS_TITLE` → `$TRADE_CATEGORY_FAVORS$` зафиксирована аудитом, но не входит в перевод: её исправление меняет исходный служебный токен и требует отдельного согласования.

## 3. Реализация

Мод разместить в `UIOD_RUS/`. Переводы оформить отдельными файлами переопределения русских ключей в `localisation/replace/`:

- `uiod_rus_ui_overhaul_l_russian.yml` — 12 ключей основного UIOD;
- `uiod_rus_ascension_slots_l_russian.yml` — 7 ключей Ascension Slots.

Имена файлов имеют префикс нового мода `uiod_rus_`. Ключи внутри файлов остаются оригинальными: это переопределения существующих строк, а не новые идентификаторы.

Создать `descriptor.mod` с именем `UI Overhaul Dynamic - Russian Localization Fix`, версией `0.0.3`, целевой версией игры и зависимостями от UI Overhaul Dynamic и UI Overhaul Dynamic - Ascension Slots. В порядке загрузки разместить UIOD_RUS после этих модов. Дополнительные зависимости от трёх остальных UIOD-модов не нужны.

Мод содержит только локализацию и метаданные. Исходные файлы игры и Workshop используются для чтения; GUI, события, технологии и баланс не изменяются.

## 4. Сохранение формата строк

Меняется только переводимый текст внутри значений. Для каждой строки сохранить:

- оригинальный ключ, регистр, двоеточие, наличие или отсутствие числового индекса после двоеточия, отступ и кавычки;
- точный состав, количество и порядок служебных токенов: `$...$`, `[...]`, `§H`, `§G`, `§!`, `£...£` и других присутствующих кодов;
- буквальные последовательности `\n`, их количество и распределение текста по исходным строкам интерфейса;
- подстановки `$UI_OVERHAUL_VERSION$`, `$tech_ascension_theory$` и все выражения с `global_event_country` и `This`;
- числа в тексте, включая ограничение 100, а также смысл выделения цветом.

Подстановки не раскрывать вручную. Не заменять `\n` физическими переносами внутри значения и не превращать их в `\\n`. Одна локализационная запись занимает одну физическую строку.

Файлы сохранить как UTF-8 с BOM, с заголовком `l_russian:` и окончанием имени `_l_russian.yml`. Использовать окончания строк LF, как в проверенных исходных файлах UIOD. Сохранение оболочки каждой записи проверять отдельно от переведённого содержимого.

## 5. Терминология и глоссарий

Английские термины искать в локализации установленной игры, затем сопоставлять русские строки по ключам. Приоритет: `Localisation_Base/1-Prio_Russian_Localization_Fix_RE/replace/`, остальные тексты Russian Localization Fix RE, затем `Localisation_Base/2-Prio_Vanilla/`.

Проверенные соответствия для этой задачи:

| Английский термин | Русский эквивалент | Ключи источников |
| --- | --- | --- |
| Ascension Theory | Теория вознесения | `tech_ascension_theory` |
| Ascension Perks | Бонусы за стремление | `ASCENSION_PERKS`, `TUTORIAL_ASCENSION_PERKS_DESC` |
| Ascension Perk Slot | Ячейка бонусов за стремление | `TUTORIAL_ASCENSION_PERKS_DESC`, `NUM_ASCENSION_PERK_SLOTS_TRIGGER` |
| Traditions | Традиции | `TRADITIONS` |
| Tradition Categories | Категории традиций | `TRADITION_COST_MULT_NUM_GROUPS`, `NUM_TRADITION_CATEGORIES` |
| Repeatable Technology | Повторяющаяся технология | `exploration.400.hint`, `NUM_REPEATABLE_TECHS_TRIGGER` |

В `replace` определений перечисленных ключей не найдено; использованы следующие по приоритету тексты Russian Localization Fix RE, подтверждённые ванильной локализацией.

При реализации внести эти термины в `Glossary/uiod_rus_terms.json` либо дополнить уже существующие записи общего глоссария. Уникальность термина проверяется по всей папке `Glossary`, а не только внутри одного файла.

Каждая запись содержит `english`, `russian`, `sources`. Массив `sources` хранит ключи и пути подтверждающих английских и русских строк, с указанием приоритета русского источника. Один термин имеет одну запись; разные источники и грамматические формы не создают дубли термина.

## 7. Состав результата

Игровая поставка:

- `UIOD_RUS/descriptor.mod`;
- два файла из `UIOD_RUS/localisation/replace/`, указанные в разделе 3.

Рабочая документация и данные:

- это ТЗ: `UIOD_RUS/Docs/TZ_RU.md` и `TZ_EN.md`;
- инструкция по подключению и проверке: `UIOD_RUS/Docs/README_RU.md` и `README_EN.md`;
- changelog: `UIOD_RUS/Docs/CHANGELOG_RU.md` и `CHANGELOG_EN.md`, с записью каждой итерации;
- отдельный список затронутых ванильных файлов и функций: `UIOD_RUS/Docs/VANILLA_CHANGES_RU.md` и `VANILLA_CHANGES_EN.md`; для данного мода список пуст, что фиксируется явно;
- JSON-глоссарий в общей папке `Glossary/`.

Рабочую документацию, глоссарий и результаты проверок не включать в игровую поставку. Для временных проверок использовать `TMP/UIOD_RUS/`. Подключение выполняется через пользовательский каталог модов Stellaris; каталог установленной игры и Workshop не изменяется.

## 8. Проверки и приёмка

Синтетические проверки после реализации:

1. В двух файлах ровно 19 уникальных ключей из раздела 6: 12 и 7 соответственно.
2. Для каждого ключа существует исходная строка в соответствующем установленном UIOD-моде.
3. BOM, заголовок языка, имена файлов, LF, кавычки и оболочка записей соответствуют разделу 4.
4. Последовательности подстановок, цветовых кодов, значков и экранирования полностью совпадают с исходными строками.
5. Все 19 значений содержат русский перевод; сохранённые английские собственные имена не считаются пропусками.
6. JSON-глоссарий читается, не содержит дублей терминов и повторных ссылок; указанные файлы и ключи источников существуют.
7. Манифест согласован с ТЗ; игровая поставка содержит только указанные файлы.
8. Документация двуязычная, оглавления соответствуют разделам.

Пользователь проверяет в игре: окно информации UIOD, ссылки и подсказки Discord и Steam, подсказки дерева технологий и перемещения окон/строк, диалог настройки Ascension Slots и информационный диалог. Проверить подстановку версии и чисел, цвета, значки, переносы, отсутствие обрезанного текста и видимых необработанных ключей. Если строка Open Beta сейчас не используется интерфейсом, для неё достаточно проверки файла до появления соответствующего экрана.

Синтетические проверки не означают, что игровая проверка выполнена. Исправление выявленных проблем вне этого ТЗ отдельно согласовывается с пользователем.
