## Профиль и запуск

Статус — реализовано. Команда `prepare-all --config <профиль>` принимает один из существующих ключей `--rebuild-libraries` или `--reuse-libraries`. Эталонный профиль принадлежит WEB_STTV. В нём заданы корни источников, состав файлов, приоритеты языков и пути результатов. [Профиль WEB_STTV](../../../WEB_STTV/config/parser_sources.json)

1. После чтения профиля координатор запускает один отдельный процесс локализации. Одновременно скриптовая часть подготавливает или проверяет пять библиотек. `batch.workers` задаёт предел рабочих процессов скриптовой части. При значении 10 могут одновременно работать до десяти процессов скриптовой части и один процесс локализации.
2. Процесс локализации за один вызов существующего обработчика читает все настроенные YML для RU и EN, проверяет конфликты и записывает словарь. Ему нужны только настройки и входы локализации. Приоритет переводов задаёт профиль: для русского языка это `replace` мода исправлений, его русская локализация, затем ванильная. Для английского используется ванильная английская локализация. Внутри одного приоритета определения упорядочиваются по относительному пути и номеру строки.
3. Когда библиотеки готовы, скриптовая часть обрабатывает TXT и DLC из `batch.sources`. Каждый элемент списка задаёт точный путь либо маску относительно корня. Сегмент `**` означает ноль или более подкаталогов. Действуют правила приоритета корней, точных исключений и устранения повторов. Свободный рабочий процесс берёт из очереди один файл по убыванию размера, при равенстве — по относительному пути. Для TXT, включая `dlc_metadata/dlc_info.txt`, и для `dlc/**/*.dlc` парсер записывает JSON с исходным путём в `source.file`.
4. Координатор дожидается завершения обеих задач и возвращает результат общего прогона. Для успеха требуются успешная подготовка скриптов и успешная запись словаря.

## Результат

| Выход профиля | Содержание |
| --- | --- |
| `batch.output` | Один раскрытый JSON на исходный TXT или DLC с сохранением относительного пути, дерева и истории раскрытий |
| `localization.output` | Существующий словарь, подготовленный для загрузчика. Один документ на пару `language`, `key`. Сохраняются исходные строки, источники и выбор по приоритету |
| `library_directory` | Пять библиотечных JSON и манифест для повторных запусков парсера |

Выходные пути отсчитываются от файла конфига. Связи с локализацией сохраняются в игровых данных в исходном виде. Подстановку названий и описаний в объекты выполняет отдельное серверное обогащение. Завершение команды означает, что подготовлены обе группы входных данных для загрузчика. Сводка и ошибки выводятся в консоль. Каталог `artifacts` содержит только выходные артефакты.

## Приёмка

- На фикстуре проверить обычный TXT, файл во вложенном каталоге, метаданные DLC, дескриптор DLC и строки RU/EN, включая строку, переопределённую модом. Результат для каждого вида совпадает с действующим профильным обработчиком.
- На фикстуре с `batch.workers = 2` проверить, что обработчик локализации запускается один раз и может начать чтение до завершения подготовки библиотек. Удержать его активным, пока два скриптовых задания выполняются одновременно. Проверить ожидание обеих задач при каждом порядке завершения. Сравнить игровые JSON с результатом при `batch.workers = 1`, а пакеты словаря и его манифест — побайтно с отдельным запуском `prepare`.
- Проверить оба режима библиотек. Ошибка разбора скрипта или конфликт определений локализации в выбранном приоритете дают ненулевой код общей команды.
- Сверить пути игровых документов с предыдущим прогоном 30 наборов и состав локализации с каталогами профиля. Для установки, проверенной 20 ноября 2026 года, контрольный состав — 619 игровых файлов и 706 файлов локализации. Эти числа описывают снимок игры. Приёмка ограничена парсером.

## Результаты проверки

20 ноября 2026 года прошли все 17 тестов парсера. На фикстуре подтверждены одновременное выполнение двух скриптовых заданий и одного задания локализации, оба порядка завершения и совпадение пакета словаря с отдельным запуском. [Проверка процессов](../tests/test_prepare_all_parallel.py) · [Проверки команды](../tests/test_prepare_all.py)

Прогон эталонного профиля с пересборкой библиотек и десятью скриптовыми процессами занял 178,63 с. Все 619 игровых JSON побайтно совпали с предыдущим прогоном. Словарь был готов за 21,5 с и содержит 153 242 русских и 150 258 английских документов из 706 файлов. После прогона проверены контрольные суммы пяти библиотек и всех 304 пакетов словаря.
