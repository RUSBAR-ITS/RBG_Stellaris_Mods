## Контракт

В корне пакета размещается `manifest.json`. Поле `format` содержит `stellaris.documents.v1`, `collection` указывает логическую коллекцию, `documents` — суммарное число документов. Каждый элемент массива `batches` содержит относительный `path`, `count` и `sha256`. Файл `batches/<sha256>.json` содержит массив документов с собственными `_id`. Порядок полей составного идентификатора сохраняется.

## Использование

После установки через `python -m pip install ./Instruments/Document_Package` производитель вызывает `write_batch` для каждой партии и `commit_manifest` после успешной подготовки всех партий. Читатель открывает `Package(directory)` и получает проверенные партии через `batches()`. Библиотека использует стандартную библиотеку Python. [Код формата](document_package/package.py)
