# Проверка документации

## Оглавление

- [Запуск](#запуск)

## Запуск

Из корня репозитория выполнить

```powershell
python -B Instruments/Documentation/check_documentation.py WEB_STTV
```

Команда читает Markdown в корне переданного проекта и на верхнем уровне его каталога `Docs/`. Выводит ошибки в JSON. Код возврата 1 означает, что найдены замечания.
