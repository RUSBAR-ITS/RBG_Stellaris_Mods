## Сборка

Команды запускаются из корня репозитория в окружении [парсера Stellaris](../Stellaris_Parser/README_RU.md). Сборка рассчитана на Stellaris 4.6.0. Она читает установленную игру и записывает четыре текстовых файла в `RB_LE/mod`. В игровой поставке нужны только сгенерированные определения, скрипты меню и локализация.

```powershell
python -B Instruments/RB_LE_Portraits/build.py --game E:/SteamLibrary/steamapps/common/Stellaris
python -B Instruments/RB_LE_Portraits/build.py --game E:/SteamLibrary/steamapps/common/Stellaris --check
python -B Instruments/RB_LE_Portraits/verify.py --game E:/SteamLibrary/steamapps/common/Stellaris
```

В `gfx/portraits` находятся собственные определения портретов и селекторы слоёв. В `common/scripted_effects` файлы `rb_le_portrait_lookup.txt` и `rb_le_portrait_choices.txt` распознают портрет и устанавливают параметры образца. Наборы выбираются из ванильного редактора видов, обычных роботов и результатов возвышения предразумных видов. Фенотипы определяются по правилам лидера и правителя с учётом пола. Списки деталей используют разные файлы DDS в порядке их объявления. При смене фенотипа сохраняются общие ресурсы и выбранный цвет глаз современных людей.

## Проверка

Каждому полному облику соответствует отдельный графический ключ. Для его украшения и одежды заданы селекторы с одним файлом DDS по умолчанию. Проверка сравнивает эти файлы с вариантами установленной игры для каждого фенотипа, проверяет обратное чтение полного ключа и циклическое переключение вариантов.

Проверка раскрывает шаблоны кнопок и считает вложенные вызовы скриптовых эффектов от каждого экрана портрета. Предел инициализации в Stellaris 4.6.0 равен пяти. Выбор фенотипа и отрисовка должны встречаться по одному разу во всём раскрытом дереве событий, оба вызова в `rb_le.27`. Это проверяет регрессию запуска версии 0.0.10. Запуск игры проверяется отдельно.

`--check` сравнивает все четыре файла с новой сборкой в памяти. `verify.py` разбирает опубликованные определения, проверяет ссылки и диапазоны и находит DDS в игре и её архивах. В ванили отсутствуют селекторы украшений `mammalian_ar_02`, `_03`, `_07`, `_09` и `_10` с суффиксом `_hair`. Для `bio7` отсутствуют маски двух дополнительных стадий. Особенности проверки в игре приведены в [ТЗ редактора](../../docs/RB_LE/DOSSIER_MENU_REQUIREMENTS_RU.md#прототип-редактора-портрета).
