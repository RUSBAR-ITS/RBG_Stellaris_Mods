The PDE 2.0.3 main menu has four entries in the order shown below. Within each section, a screen contains either subfolders or a list of actions. The words **deposit list** stand for all deposit buttons in that folder. Empty folders are hidden for the selected body. Each page holds up to ten visible entries. Page controls, Back and Close appear separately.
