## Объём выпуска

**Утверждено пользователем 23 ноября 2026 года.** Переписать Planetary Deposits Editor как самостоятельный чит-редактор для ванильной Stellaris 4.5.4. Поставка находится в `PDE/`, версия мода — `2.0.0`, поле дескриптора — `supported_version="v4.5.*"`. Перенести механизм динамического меню RB_SDM под имена PDE. Игровые идентификаторы используют префикс `cdpd_`, события — пространство имён `CDPD`. Поставить русскую и английскую локализации. ## Доступ и выбор цели

Планетарное решение открывает редактор **только для игрока**. Проверять страну-инициатора в `from`, задать вес ИИ 0 и открывать сеанс только для державы игрока. Использовать штатное окно решений в границах державы на собственной колонии или незаселённом теле. Чужая колония, включая досветовую, подчиняется ванильному правилу доступа. Сохранить выбранное тело для текущего сеанса державы. Перед действием повторно проверить цель и доступ. При утрате цели завершить сеанс. [Требования к входу](REQUIREMENTS_RU.md#состояние-проекта)

Для добавления использовать конечную колонку **«Где добавлять»** справочника. На одинаковой подходящей цели у игрока один набор ID при любом типе державы, происхождении, уровне технологий и состоянии квестов. Условия самой планеты продолжают действовать. Например, для `d_irradiated_ruins` нужен существующий `irradiated_planet` на колонизируемом мире, кроме `pc_ark`. [Правила и исключения по ID](DEPOSIT_CLASSIFICATION_RU.md#размещение-по-id)

## Каталог и меню

- Предусмотреть **529 ID для добавления и 592 ID для удаления**, в том числе 63 ID только для удаления. `d_null_deposit` служит заполнителем. Один ID имеет одну запись каталога и по одному пункту в каждом применимом списке.
- Для дерева меню действует утверждённая схема PDE 2.0.3. [Структура меню PDE](MENU_STRUCTURE_RU.md) Скрывать раздел на любой глубине, когда среди всех его потомков нет доступного депозита. Верхний пункт «Удалить депозиты» открывает плоский список ID на выбранном теле, включая ванильные и исключённые из добавления. Пустой пункт удаления скрывать.
- Сначала считать доступные пункты, затем выводить их в том же порядке, по 10 на страницу. Подкатегория занимает одно место, навигация идёт вне лимита. После каждого действия пересчитать список и предков. При исчезновении текущей страницы перейти на последнюю доступную, а при опустевшем разделе — к доступному родителю.
- Кнопка ссылается на локализованное имя и полное описание. Для помеченного действия вывести красное предупреждение в самом верху, затем пустую строку, имя и описание. Использовать раздельные списки для добавления и удаления и обычный размер шрифта штатной подсказки. [Реестр предупреждений](QUEST_TOOLTIP_WARNINGS_RU.md) · [Поля кнопки](PROJECT_LAYOUT_RU.md#из-чего-состоит-кнопка-депозита)

## Экземпляры и состояние планеты

**Каждый из 529 разрешённых ID можно добавлять повторно**, включая сюжетные и уникальные особенности. Наличие такого же ID на теле не скрывает кнопку. Один клик создаёт один дополнительный экземпляр. После первого добавления в меню удаления появляется одна строка этого ID. Один клик удаления выбирает на сохранённом теле один экземпляр по `is_deposit_type` и выполняет `remove_deposit = yes` на нём. Строка исчезает после последнего экземпляра. Для блокеров выполнить прямое удаление, сохранив прочие особенности тела и сняв блокировку, которую создавал выбранный экземпляр. [Ванильный пример удаления одного экземпляра](E:/SteamLibrary/steamapps/common/Stellaris/common/decisions/07_overlord_decisions.txt:44)

Собственные выработка, должности, районы, содержание и условные бонусы определяются ванилью. Количество экземпляров само по себе не гарантирует умножения каждого эффекта. Проверить также эффекты, заданные вне определения депозита. Действия редактора не запускают расчистку, спецпроекты или квесты и не выдают их награды.

| Состояние | Поведение PDE |
| --- | --- |
| `d_titanic_life_blocker` и `titanic_life` | Обеспечить один модификатор при любом положительном числе экземпляров. После удаления проверить оставшиеся экземпляры и другие действующие источники. Снять модификатор после удаления последней зависимости, в том числе для ванильной пары. При первом добавлении на тело без зависимых депозитов запомнить, был ли модификатор уже активен самостоятельно. Перед снятием проверить, сохраняется ли независимый источник, и очистить учёт PDE после последнего экземпляра. Состояние пары определять по депозитам и подтверждённым источникам на теле. Одного факта наличия модификатора недостаточно для определения его источника. |
| `seed_bomb_blockers` | Общий счётчик для `d_seed_bombing_fungoid_blocker` и `d_seed_bombing_plantoid_blocker`. Учитывать по одному вкладу на экземпляр обоих типов. |
| `seismic_bombing_var` | Учитывать по одному вкладу экземпляров `d_seismic_bombing_crater`. |
| `pyrolatry_var` | Учитывать вместе `d_large_volcano`, `d_ash_storms`, `d_charged_atmosphere`, `d_lava_flooding` и `d_toxic_atmosphere`, в том числе повторные экземпляры одного ID. |
| Состояние квеста или независимого объекта | Прямое удаление `d_stasis_pods` сохраняет прогресс `cd_pods_var`. Удаление `d_spawning_complex_blocker` сохраняет владение сюзерена. Существующее радиационное заражение сохраняется при обеих операциях с руинами. |

Для трёх служебных счётчиков изменение ограничено вкладом одной операции. После последнего учтённого вклада снять переменную. При исходно отсутствующем счётчике прямое удаление не создаёт отрицательное значение. Для добавления и удаления использовать только служебную часть ванильных действий. Источники и действия расчистки приведены в [реестре зависимостей](VANILLA_CHANGES_RU.md#состояние-планеты).

## Приёмка

| Проверка | Критерий |
| --- | --- |
| Каталог и скрипты | Сопоставить ID готовых каталогов со снимком 4.5.4. Проверить количества 529 и 592, совпадение проходов подсчёта и вывода, привязку обоих действий, ветки событий, ключи RU/EN и наборы предупреждений (205 для добавления, 84 для удаления). |
| Доступ и тип державы | В одной и той же подходящей системе игрок получает одинаковый список для обычной державы, коллективного разума и машинного интеллекта. Держава под управлением ИИ не принимает решение. |
| Повторное размещение | Пройти 0 → 1 → 2 → 1 → 0 для `d_energy_3` на подходящей звезде и для проекта «Изобилие» (`d_project_cornucopia`) на подходящей планете. Кнопка добавления доступна на каждом шаге. Проверить одну строку удаления и изменение количества и эффектов после каждого клика. |
| Общие эффекты | Проверить по два экземпляра титанической особенности, включая ванильную пару и независимый источник модификатора. Для общих счётчиков проверить повторные экземпляры, смешанные типы и прямое удаление при исходно отсутствующей переменной. Отдельно проверить, что у блокера исчезает его вклад, а награда за расчистку не выдаётся. |
| Меню и подсказки | Для 89 доступных пунктов из 200 получить девять страниц (10 × 8 + 9). Проверить исчезновение пустой глубокой ветки, удаление последнего ID на последней странице и порядок текста подсказок в RU/EN. |

Синтетические проверки выполнять на готовых игровых файлах. Доступность решения в интерфейсе, фактическое число экземпляров, пересчёт бонусов, переходы и подсказки проверяет пользователь в игре. [Подробные сценарии проверки](REQUIREMENTS_RU.md#примеры-для-проверки)
