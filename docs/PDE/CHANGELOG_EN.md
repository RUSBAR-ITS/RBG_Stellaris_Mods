## 2026-11-23 — PDE 2.0.0 implementation

- Created the local launcher descriptor `mod/PDE.mod` for testing. It points directly to the repository’s `PDE/` directory.
- The decision opens a standalone PDE menu on an owned colony or uncolonized body in player-owned space. Placement uses the selected body’s rules. Empty branches are hidden, with up to ten available entries per page.
- Placement covers 529 IDs. The flat removal list covers 592 IDs and shows only types present on the body. Each click affects one instance. PDE removes blockers directly and maintains the paired modifier and three vanilla counters. [Effects and limitations](VANILLA_CHANGES_EN.md#planet-state)
- Both localizations display red warnings before the name and description for 205 placement actions and 84 removal actions. For seven deposits without a vanilla description, the tooltip shows monthly station output.
- Script checks compared the catalog with the 4.5.4 snapshot, expanded nested scripts and verified references, pagination and repeated operations. In-game verification of the interface, instance counts and actual bonuses is pending. [Acceptance scenarios](TZ_EN.md#acceptance)
