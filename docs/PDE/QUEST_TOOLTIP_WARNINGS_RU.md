## Правила показа

Рабочий список для Stellaris 4.5.4. Единица учёта — ванильный ID. У каждой кнопки свой список. Пометка действует для ID на любом разрешённом теле, даже если сейчас цепочка не активна. Предупреждение сообщает о возможном последствии, а кнопку по-прежнему можно нажать.

Проверены 592 депозита и блокера. Для добавления отмечены **205 из 529** доступного ID, для удаления — **84 из 592**. У **31** ID отмечены обе кнопки. Для **334** предупреждений нет.

При **добавлении** пометка означает, что особенность представляет место, стадию или узнаваемый результат конкретной истории, аномалии, раскопок, проекта, миссии или ситуации. PDE устанавливает саму особенность. Начальные условия, таймеры и дальнейшие события обрабатывает ваниль. Обычная залежь, которую событие использует как типовую выплату, сама по себе такой пометки не получает.

При **удалении** пометка означает, что изменение может лишить начатое задание цели, варианта ответа, продвижения или части результата. Учтены проверки типа депозита, обязательные условия проекта, действия при расчистке и выбор цели по ресурсу. Для группы взаимозаменяемых залежей риск обычно возникает при удалении последней подходящей цели. Изменение общего дохода державы само по себе в список не входит.

Подсказка начинается с предупреждения для выбранного действия. Через пустую строку выводится название депозита, под ним — полное описание. Красный цвет начинается перед словом «ВНИМАНИЕ» и заканчивается сразу после фразы. Для удвоенного размера нужен подтверждённый способ изменить только этот абзац. В стандартном тултипе опции RB_SDM используется один ключ `custom_tooltip`, а игровое окно задаёт один шрифт `cg_16b`. В исследованных ванильных локализациях не найден пример изменения размера части строки. Для текущего варианта предусмотрен обычный размер. ## Проверка в игре

На одном сохранении сравнить подсказки первой и последней стадии одинокого робота, обычного `d_trade_value_1` и доступного только для удаления `d_shimmering_structure`. В обеих локализациях проверить, что у отмеченного действия сначала видно красное предупреждение, затем через пустую строку — название в обычном оформлении и под ним полное описание. У действия без пометки первой строкой должно быть название. На копии сохранения с активной миссией ангаров сравнить счётчик после прямого удаления и после штатной расчистки.
