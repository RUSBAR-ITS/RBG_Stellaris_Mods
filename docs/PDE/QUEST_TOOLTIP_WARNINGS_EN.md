## Display rules

Working list for Stellaris 4.5.4. Each entry refers to one vanilla ID. Each button has its own list. A listed ID gets the warning on any eligible body, including when the chain is inactive. The button stays available.

Of 592 substantive IDs, **205 of 529** placeable deposits have a placement warning and **84 of 592** have a removal warning. **31** appear in both lists. **334** have neither warning.

A **placement** warning identifies a location, stage or distinctive outcome of a specific story, anomaly, excavation, project, mission or situation. PDE places the feature. Vanilla controls the opening conditions, timers and later events. An ordinary resource used as a generic payout does not qualify on that basis alone.

A **removal** warning identifies a possible loss of a target, choice, progress or part of the outcome of an active quest. The list covers type checks, project dependencies, clearance callbacks and targets selected by resource. For interchangeable deposits, removing the last eligible target usually creates the risk. Changes to general empire income fall outside this criterion.

Start the tooltip with the warning for the selected action. Leave a blank line, then show the deposit name with its full description below. Start red immediately before “WARNING” and reset it after the final punctuation. Doubling the size requires a way to scale only this paragraph. The RB_SDM event option takes one `custom_tooltip` key and the vanilla tooltip window uses one `cg_16b` font. The vanilla localization files examined provide no example of a size change within the string. The current design therefore uses the normal size. ## Boundary cases

- **Lonely Bot.** Placing any of the three IDs does not reproduce the anomaly. Removing the first or second stage can prevent an already scheduled follow-up. The third stage is awarded by the final choice. [First stage check](E:/SteamLibrary/steamapps/common/Stellaris/events/colony_events_3.txt:2907) · [Second stage check and third stage award](E:/SteamLibrary/steamapps/common/Stellaris/events/colony_events_3.txt:3049)
- **Shimmering Structure and Broken Shackles debris.** Both blockers are excluded from placement. The structure’s follow-up runs on a timer and its reward is placed separately. The Broken Shackles excavation stage issues its reward and removes the debris independently. No quest removal warning was identified for either blocker. The memorial decision checks the crashed ship itself. [Timer](E:/SteamLibrary/steamapps/common/Stellaris/events/strange_worlds_events.txt:334) · [Outcome](E:/SteamLibrary/steamapps/common/Stellaris/events/strange_worlds_events.txt:476) · [Excavation stage](E:/SteamLibrary/steamapps/common/Stellaris/events/origin_events_broken_shackles.txt:1479) · [Memorial](E:/SteamLibrary/steamapps/common/Stellaris/common/decisions/08_first_contact_dlc_decisions.txt:19)
- **Titanic Lifeforms.** Placing the required `titanic_life` modifier can make the colony eligible for a later vanilla event. An existing project resolves through its own callback and the award does not require the deposit. Likewise the Dreamer’s sanctum project starts and resolves separately from the placement and cleanup of `d_ruined_sanctum_of_the_lost`. Both IDs carry the placement warning. [Titan study opening](E:/SteamLibrary/steamapps/common/Stellaris/events/colony_events_3.txt:169) · [Projects](E:/SteamLibrary/steamapps/common/Stellaris/common/special_projects/00_projects_3.txt:605) · [Reward](E:/SteamLibrary/steamapps/common/Stellaris/events/colony_events_3.txt:307) · [Sanctum project](E:/SteamLibrary/steamapps/common/Stellaris/common/special_projects/04_projects_shroud.txt:540)
- **Ordinary orbital resources.** Removing the last qualifying deposit from the selected system can cost a nomadic contract its deposit upgrade. The script pays the main reward separately. The three contracts do not test trade deposits. Their use in screening dig site spawns creates no dependency in an excavation already underway.
