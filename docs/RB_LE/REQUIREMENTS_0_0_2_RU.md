## Первый тест

Согласованный сценарий заменяет кнопку в карточке лидера планетарным решением «Отдел Кадров». Решение на собственной колонии открывает реестр всей державы игрока. Редактор работает в штатном интерфейсе Stellaris `v4.6.*`. В комплекте русские и английские тексты. Просмотр дела сохраняет свойства персонажа.

## Экраны и переходы

| Экран | Текст | Кнопки |
|---|---|---|
| Решение «Отдел Кадров» | В кадровом реестре державы хранятся личные дела правителя и лидеров на службе. Подсказка эффекта — «Открывает кадровый реестр державы». | Принять решение |
| Отдел Кадров | Держава: ‹название›. Через пустую строку — «Выберите раздел кадрового реестра». | Правитель, Командиры, Чиновники, Учёные, Выйти |
| Дело правителя | Здесь хранится личное дело действующего правителя. Выберите имя, чтобы открыть его. | Имя правителя |
| Реестр командиров | Выберите командира, чтобы открыть его личное дело. | Имена командиров |
| Реестр чиновников | Выберите чиновника, чтобы открыть его личное дело. | Имена чиновников |
| Реестр учёных | Выберите учёного, чтобы открыть его личное дело. | Имена учёных |
| Личное дело | Имя: ‹имя выбранного лидера› | Назад, Выйти |

Главное меню скрывает пустые разделы. В списках участвуют нанятые лидеры с назначением и без него. Правитель также доступен в реестре своего класса. Кандидаты из резерва появляются после найма.

В реестре на страницу отводится десять имён. При нескольких страницах после текста через пустую строку выводится «Страница S/N», после имён доступны переходы на существующие соседние страницы. Внизу каждого списка — «Назад» и «Выйти». «Назад» из дела возвращает в исходный раздел на прежнюю страницу, из списка — в главное меню. «Выйти» завершает просмотр.

## Приёмка

Проверить видимость решения на своей колонии, порядок и скрытие пустых разделов, имя правителя обоими маршрутами, попадание свободного нанятого лидера и исключение кандидатов. При одиннадцати лидерах одного класса открыть последнее имя, вернуться на вторую страницу и выйти. При повторном открытии начать с главного меню. Сверить имена с окном лидеров и проверить журнал игры.
