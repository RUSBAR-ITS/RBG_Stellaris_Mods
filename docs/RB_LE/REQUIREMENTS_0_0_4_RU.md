## Поля личного дела

В «Отделе Кадров» четыре реестра открывают общее досье выбранного лидера. Согласованный экран доступен на русском и английском языках для Stellaris `v4.6.*`. Просмотр сохраняет данные персонажа.

| Раздел | Сведения |
|---|---|
| Личные сведения | Имя, возраст, выслуга, название и класс собственной расы лидера, тип для условий черт и текущий личный принцип. Органика и синтетика определяются по расе персонажа. |
| Происхождение | Родной мир и его тип, когда доступны, либо название родной мобильной колонии. Отдельной строкой выводится прежняя профессия. Если оба сведения отсутствуют, скрывается весь раздел. |
| Подготовка | Класс, полученная специализация, базовый уровень, действующий уровень навыка при отличии от базового и текущий опыт относительно порога следующего уровня. По достижении предела выводится штатная надпись о максимальном уровне. |

Необязательные строки появляются при наличии сведений. «Назад» возвращает к исходной странице реестра, «Выйти» закрывает меню. Экран предназначен для просмотра.

Дополнение 0.0.6. Сразу после имени отдельная строка показывает пол выбранного лидера. Подпись и три значения берутся из действующей локализации игры.

## Проверка в игре

1. Сопоставить личное дело правителя, открытое через оба реестра, с ванильной карточкой. Выбрать другого персонажа и сверить происхождение, вид и этику.
2. Сравнить опыт лидера с частично заполненной шкалой и её порог с обоими числами в ванильной подсказке. Проверить базовый и действующий уровни при бонусе, отсутствие второй строки при равенстве и сообщение на максимальном базовом уровне.
3. Проверить синтетика, лидера-гештальта без профессии, лидеров со специализацией и без неё, а при наличии — уроженца ковчега. Проверить русские и английские строки, прокрутку длинного досье, возврат на вторую страницу реестра и выход.
4. Открыть по очереди досье лидеров с разным полом. Проверить строку между именем и возрастом, в том числе у персонажа с `gender = indeterminable`.
