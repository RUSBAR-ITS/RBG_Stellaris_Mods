[b]Planetary Capacity Extender 2.0.1 для Stellaris v4.6.*[/b]

Небольшой чит-мод, который позволяет бесплатно увеличить общий лимит районов на любой своей колонии. Он работает на заселённых планетах, орбитальных поселениях, обитаемых сегментах мира-кольца и кораблях-ковчегах. Прибавка действует только на выбранную колонию. Сами районы вы строите как обычно.

[h2]Как изменить лимит районов[/h2]

Выберите колонию, откройте [b]«Решения»[/b] и нажмите [b]«Планирование инфраструктуры колонии»[/b]. В меню показан текущий индекс вместимости. Каждая единица индекса даёт одну дополнительную ячейку района. Решение доступно только игрокам.

[list]
[*]Чтобы добавить ячейки, выберите увеличение и нужное количество от 1 до 10. Действие можно повторять.
[*]Чтобы убрать часть прибавки, выберите уменьшение. В меню доступны только те значения, которые можно снять. Команда [b]«Снять всё»[/b] убирает всю прибавку этой колонии.
[/list]

[b]Индекс меняется сразу. Новый лимит районов вступает в силу в течение нескольких игровых дней.[/b]

[h2]Где посмотреть прибавку[/h2]

В списке особенностей колонии есть карточка с общей прибавкой к лимиту районов. Мод выбирает один из 49 вариантов карточки в зависимости от типа колонии и державы. После терраформирования или смены владельца карточка может измениться. Накопленная прибавка сохраняется.
