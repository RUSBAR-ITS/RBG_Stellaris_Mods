# PIF preset index

Preset index for **PIF - More Secondary Zones and Building Slots** compatibility.

The active root `interface/zz_bpv_planet_view.gui` is intentionally left unchanged. To activate a visual preset, copy the preset folder's `interface` directory into the mod root and replace files.

## Naming convention

```text
Sxx_Gxxx_MSxxx_Rxxx
```

| Token | Meaning | Gameplay values |
|---|---|---|
| `S` | Secondary zone slots | `3`, `5`, `10`, `20`, `30` |
| `G` | Government / `zone_default` building slots | `12`, `24`, `48`, `96`, `120` |
| `MS` | Main secondary zone building slots | `6`, `12`, `18`, `24` |
| `R` | Resource / lower district building slots | `6`, `12`, `18`, `24`, `48` |

Default gameplay combination: `S05_G024_MS012_R024_default`.

## Formula summary

```text
city_rows = ceil(G / 6)
secondary_rows = ceil(MS / 6)
lower_rows = ceil(R / 3)
secondary_entry_height = secondary_rows * 52 + 2
secondary_required_height = 35 + 10 + ((secondary_entry_height + 10) * S) - 10
city_required_height = 35 + 10 + city_rows * 52
main_card_height = max(264, city_required_height, secondary_required_height)
lower_required_height = 35 + 20 + lower_rows * 52 + 10
lower_card_height = max(280, lower_required_height)
lower_grid_row_height = lower_card_height + 10
lower_scroll_content_height = lower_grid_row_height
```
