## Проверка стенда

На стенде выполнены удаление и создание базы `wiki`, импорт и сверка с входными документами. Итоговые 110 исходных коллекций содержат 346 641 документ, включая 304 812 строк локализации, 28 действий с малыми артефактами и 436 проектов кораблей. После публикации последней версии локализации загрузчик повторно сверил всю коллекцию из настроенного входного каталога. Для остальных 109 коллекций проверено сохранение UUID предыдущей полной сверки.

Исходный аудит охватывает 1 084 прямые команды с именами технологий. Для 1 078 найдены исполнения, оставшиеся шесть принадлежат двум тестовым событиям. Ещё 128 мест используют динамический выбор. Для 127 найдены вызовы, пример сделки караванщиков остался без точки вызова в этом снимке.

Число технологий с подтверждённой именованной наградой выросло с 478 до 490. Для 290 технологий найдено открытие варианта исследования, для 261 — выдача изученной технологии, для 305 — частичный прогресс. Группы пересекаются. При сверке сохранены адреса ранее показанных наград. Эффекты случайного выбора и анализ обломков учитываются отдельно.

У каждой из 97 технологий с единственным явно заданным весом 0 теперь указан хотя бы один путь. У 90 есть именованная награда, ещё у шести — анализ обломков, у одной — условная выдача на старте. Поимённый список с пересечениями способов сохранён в `zero-weight.json`.

Пройдены 37 локальных серверных проверок и три проверки с подключением к стенду. Последние охватывают поиск локализации, ошибки входных параметров и конкурентную публикацию дерева в изолированных тестовых коллекциях. Для справочника проверены общий и раздельные сбросы, повторное открытие, а также отметка об отключённом DLC у источника награды. С 36 DLC дерево содержит 678 технологий, без DLC — 464. Отдельные страницы проверяются для всех 679 ID.

В итоговой версии браузер открыл и развернул 1 358 страниц. Ошибок отображения, пропавших адресов прежних наград и нераспознанных операторов условий в этой выборке — 0. Для Синих лазеров текст карточки и страницы совпал до и после раскрытия с клавиатуры. В MongoDB проверены все 679 документов тултипов. Размер самого большого — 3 925 771 байт.

Сводка и поимённые результаты формируются в `TMP/WEB_STTV/acquisition-fixes/reports/`. Файл `source-comparison.json` связывает адрес строки игры с исполнением, `player-paths.json` хранит получателя и условия ветви, `dynamic-sites.json` содержит разбор динамических команд. В `register.json` можно искать технологию по ID и сравнивать RU и EN. В `wording-limits.json` для оставшихся общих подписей перечислены соответствующие параметры и технологии. В `release/pages.json` записан результат каждой страницы. [Программа сверки](../tests/acquisition_review.py) · [Исходное ТЗ](TZ_TECHNOLOGY_ACQUISITION_FIXES_RU.md)

Для повторной приёмки сначала снять адреса команд из установленной игры с архивами DLC и получить пути из снимка парсера. Затем пройти браузером оба языка и передать результаты в `acquisition_review.py` вместе с исходным аудитом. В `flag-limits.json` для совпадающих или общих подписей флагов сохранены места установки, владельцы и ветви, доступные в импортированных данных. [Обход файлов игры](../tests/acquisition_vanilla_sites.py) · [Обход снимка парсера](../tests/acquisition_acceptance.py) · [Браузерная проверка](../../../tests/frontend/conditionPages.mjs)

## Проверка подписей на страницах

Аудит читает название, описание, краткие сводки и развёрнутые условия на 679 страницах в каждом языке. Формулировки берутся из словарей приложения. Сообщения об отсутствии названия, общие подписи целей, неизвестные операнды, пустые логические группы и значения, зависящие от кампании, учитываются отдельно. Для каждого совпадения в отчёте есть раздел, источник, пример текста и ID технологий. [Проверка текста](../tests/audit_visible_wording.py)

На стенде браузер раскрыл все 1 358 страниц. В таблице указано число технологий с хотя бы одним совпадением в каждом языке. Одна технология может попадать в несколько строк.

| Вид подписи | До, RU / EN | После, RU / EN |
|---|---:|---:|
| Сообщение об отсутствии названия источника | 538 / 538 | 0 / 0 |
| Другие сообщения об отсутствующем названии, неизвестном модуле или переводе | 188 / 488 | 0 / 0 |
| Общая подпись сохранённой цели или объекта | 166 / 166 | 0 / 0 |
| Пустой заголовок логической группы | 33 / 33 | 0 / 0 |

Адреса прежних наград и источники сохранились. Для Синих лазеров сверены краткое и раскрытое представления карточки и страницы. Отчёты по формулировкам находятся в `TMP/WEB_STTV/condition-targets/reports/visible-before.json` и `visible-final.json`, результаты браузера — в `TMP/WEB_STTV/condition-targets-final/reports/release/pages.json`. Параметр `--check` у проверки текста возвращает ошибку, если на страницах снова появляется одна из отслеживаемых заглушек или пустая группа.

Сервер собирает блок из игровых условий, вызовов и наград. Для скрытого события можно указать действие по его скрипту, показать источник вызова или назвать цепочку. Индивидуальные названия кораблей и планет, назначаемые в партии, сохраняют описание своей роли. У отметки `Story41` подтверждено, что она исключает событие «Контакт: Предразумные существа». Способ установки в исследованных файлах установить не удалось.

## Границы проверки

В ведомости исполнений 224 записи для 85 технологий остались без подтверждённого входа в цепочку. У 685 записей для 52 технологий остаётся вопрос о получателе, ещё у 624 записей для 12 технологий он возникает в инициализаторе. У одной технологии могут быть такие записи и независимо подтверждённый способ получения. Координаты спорной команды и последовательность областей действия сохранены для разбора.

Имена правителей, планет и сохранённых целей могут определяться партией. Для технического объекта может отсутствовать строка локализации. В отчётах эти случаи учитываются раздельно. Счётчики подписей относятся ко всем раскрытым ветвям, в том числе к условиям общих наград. Один и тот же флаг в общем событии может попадать на страницы сотен технологий.

| Подпись в исходной приёмке, до исправления названий | Страницы RU | Страницы EN |
|---|---:|---:|
| Хотя бы одно недоступное имя объекта или источника | 545 | 547 |
| Общая формулировка флага | 133 | 133 |
| Разные флаги получили одинаковый видимый текст хотя бы в одном месте | 478 | 478 |
| Общая подпись сохранённой цели | 79 | 79 |
| Скрытый промежуточный этап | 121 | 121 |
| Совпадение заголовков разных источников награды | 25 | 22 |

В списке флагов с общими или совпадающими подписями для 263 пар «проверка + флаг» найдены точки установки. Для 67 пар в импортированных данных отсутствует установка с таким ключом и областью действия.

У `tech_torpedoes_1` подтверждённый проект фрегата несёт боевой компьютер с двумя пререквизитами. Скрипты не устанавливают, какой из них движок выберет для прогресса. Во флоте Инакса действует отдельный запрет обломков. Для подтверждённых носителей 10% берутся из игровой константы анализа. Фактический состав обломков после боя, выбор из случайного пула в конкретной партии и порядок применения конфликтующих объявлений веса требуют проверки в игре.
