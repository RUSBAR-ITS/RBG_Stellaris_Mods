## Условия и награды

Сервер определяет участника в месте проверки. У события различаются исходный получатель, предыдущая область внутри выражения и участники, переданные вызывающим действием. Для подписок на боевые действия учитываются стороны и флоты боя. Для особого проекта учитывается этап, для аномалии — способ вызова события. Если несколько путей дают разные роли, сервер сохраняет различие и адрес для сверки.

У Титана «Парадокс» показаны требуемое DLC и условие «Государство не использует биокорабли». В награде указан четвёртый уровень Космогенеза. На раскопках «Долгое ожидание» появляется фраза «Раскопки ведёт назначенный учёный». Проверка обнаружения родного мира ирассианцев получила собственный текст. Для других флагов, когда точное значение не установлено, выводятся известный участник и действия, установившие состояние. В диагностике доступны ID флага и адреса команд.

## Приёмка

На стенде сравнили сохранённые документы MongoDB с расчётом для всех восьми комбинаций из таблицы. Совпали доступность каждой технологии, родитель, потомки и обе пары координат. После обновления правил тот же ID дерева получил новую ревизию. Проверили также сброс деревьев и тултипов и повторное чтение уже построенного результата.

В локальном наборе из 54 серверных тестов прошёл 51. Три теста с отдельными требованиями к окружению пропущены. Проверки охватывают цикл с выходом к награде, две причины вызова одного события, положительную и отрицательную проверку биокораблей и существование необязательного владельца. В условиях появления аномалии проверяется небесное тело, в условиях выбора результата — исследующий корабль. В ограничениях подсчёта систем внутри бури различаются исходная система и каждая рассматриваемая система.

Проверка отдельных реплик опирается на ключи вариантов ответа. На странице «Улучшенные форсажные камеры» предложение подарить систему читается как «Прими в дар предложенную систему». На странице «Инопланетная топография» решение о судьбе похищенного учёного читается как «Оставить учёного среди своего досветового народа». Вне запущенной партии неизвестны имя подаренной системы и личность учёного.

В браузере открыли каждую из 679 технологий на русском и английском языках, раскрыли разделы наград и сверили содержимое с ответами сервера и адресами наград предыдущего снимка. Для «Синих лазеров» также сравнили открываемый с карточки тултип и отдельную страницу, включая раскрытие награды с клавиатуры. Последняя правка словаря затронула страницу добычи зро. Обе её версии прошли повторную проверку с названиями стартовых залежей, вновь появившихся залежей и астрального шрама. Для 526 флагов на 521 странице точное самостоятельное значение не установлено. Сервер указывает подтверждённые действия и участников, а в диагностике сохраняет ключи и адреса. Числа одинаковы в RU и EN.

В итоговом проходе на обоих языках отсутствующие названия, безымянные сохранённые объекты, пустые группы, технические заглушки и нераскрытые маркеры локализации встретились на 0 страницах. Исходные адреса наград и источников сохранились во всех 1 358 представлениях.

После обновления словаря заново запросили все 1 358 представлений через действующий API и сравнили полные ответы с браузерными снимками. Все ответы совпали. В MongoDB все 679 документов тултипов получили одну актуальную ревизию источников и правил.
