## Сводка

Повторный аудит Stellaris 4.5.4 (1b4f) проведён 21 ноября 2026 года. В Chrome на стенде повторно открыты 679 базовых технологий на RU и EN со всеми DLC. Все 1 358 страниц прошли проверку заголовков, отображения текста API и загрузки значков (768 вхождений). Для каждого ID сверены игровые условия, типы и источники наград и текущие формулировки.

478 технологий имеют хотя бы один именованный источник на странице. Вариант для исследования открывается у 289, полностью изученная технология выдаётся у 248, прогресс начисляется у 298. Разделы пересекаются. Для остальных 201 распределение следующее.

| Базовый вес на 201 странице без наград | Число | Что следует из данных |
|---|---:|---|
| Одно положительное значение | 156 | Кандидаты на обычную вытяжку с учётом пререквизитов, доступности и модификаторов. |
| Не указан | 27 | Все 27 отмечены как стартовые. |
| Одно нулевое значение | 16 | Шесть кандидатов на обломки, девять скриптовых наград и один условный старт. |
| Объявлен дважды | 2 | У роя Дайсона и орбитальной дуговой печи указаны 0 и 70. Третий конфликт, у пушки Дайсона, встречается на странице с наградой. |

## Границы проверки

Сверены тексты основной установки и DLC в common, events, map и prescripted_countries, включая отдельные DLC-файлы (2 265 текстовых файлов и 32 проверенных архива). Вне тел библиотек и блоков подсказок найдено 1 084 прямых именованных команды трёх типов. При сравнении по технологии, типу награды, файлу и объекту-источнику шесть относятся к двум событиям с is_test_event = yes и always = no. Для остальных найдено соответствие в ведомости разобранных путей. Для раскрытых вставок использована отдельная сверка источников показанных наград по всем ID. Наличие строки в скрипте само по себе не подтверждает получение игроком.

Из отчёта исключены как награды игрока явные выдачи NPC и ветви с несовместимым получателем. Условные варианты technology_swap входят в игровые определения (206 блоков), а самостоятельных опубликованных страниц у них нет. Проверялись базовые страницы со всеми DLC. Фактический состав обломков, доступные в конкретной партии технологии при случайном выборе и поведение при конфликтующих объявлениях веса остаются для проверки в игре. Порог длины — критерий отбора для просмотра, а не ошибка каждой отмеченной страницы.
