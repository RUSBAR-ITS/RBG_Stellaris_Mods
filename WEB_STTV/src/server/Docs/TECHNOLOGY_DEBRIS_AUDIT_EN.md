## Coverage

Snapshot Stellaris v4.5.4 (1b4f). Compared 679 base technologies and 1,506 components from the published MongoDB with the page responses for that snapshot. Read 436 named designs in 39 files, including section components and `required_component`. Searched installed base scripts, unpacked DLC and 32 DLC archives for use sites. Each example links to the exact component installation and a ship creation site.

An empty page here has none of the three acquisition sections (research option, completed technology, partial progress). Availability and weight conditions may still appear. There are 201 such pages. Of 97 technologies with a single explicit base weight of zero, 81 already show an acquisition source and 16 have empty sections. Another 38 of the 679 have no weight field.

Categories are mutually exclusive. Where several routes exist the strongest observed evidence determines the row.
