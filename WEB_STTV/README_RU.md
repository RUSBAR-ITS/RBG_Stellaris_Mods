## Проект

**Stellaris Technological Tree View**, каталог проекта — `WEB_STTV`.

Локальный интерактивный веб-справочник по технологиям Stellaris. Основной режим — дерево связей из карточек технологий с ванильными изображениями. Данные собираются из выбранных пользователем источников и преобразуются во внутреннюю базу справочника. Предполагается переносимая поставка для Windows без отдельной установки веб-сервера.

## Статус

Реализовано утверждённое [ТЗ шестого этапа](Docs/TZ_BACKEND_STAGE_6_RU.md): исходники → парсер и раскрытие `inline_script` → JSON с деревьями файлов. Профиль, реестр команд, связанный анализатор и прежняя предметная конверсия удалены. Локализация и вычисление связей перенесены в следующие этапы обогащения.

[Руководство шестого этапа](Docs/BACKEND_STAGE_6_RU.md) описывает запуск, формат, модули и ограничения. Штатная база — `data/database.json`, отчёт — `data/reports/build_report.json`. Новый формат: `sttv.parse_database`, версия 1; загрузчик читает его без игры и конфигурации парсера.

Проверены 78 актуальных тестов. Технологический набор: 35 файлов, 67 513 узлов, 301 раскрытая вставка из 10 шаблонов, без ошибок и предупреждений. JSON совпадает с деревьями парсера по всем полям и воспроизводится побайтно. Общий аудит: 1 583 успешных файла и прежние 22 проблемных входа; результаты и списки — в `data/stage6/`.

Исходники и прежние исследовательские списки сохранены. Руководства этапов 1–5 описывают исторические реализации. Текущая база не получает названия RU/EN и не вычисляет связи: эти действия будут проектироваться отдельно.

Код находится в `src/backend/`. Интерфейс, HTTP-служба, изображения и portable-поставка ещё не реализованы; версия программного выпуска не назначена. Для следующих этапов согласованы TypeScript, HTML/CSS и PyInstaller в режиме `onedir`.

## Структура каталога

| Путь | Назначение |
| --- | --- |
| `src/frontend/` | Код интерфейса |
| `src/backend/` | Код Python для обработки и последующей служебной части |
| `config/` | Источники, пути результатов и четыре конфига парсера |
| `schemas/` | Семь генерируемых схем конфигурации, синтаксического дерева и отчёта |
| `data/` | Рабочая папка по умолчанию для БД, отчётов, временных результатов и проверок |
| `Docs/` | Документация на русском и английском |

Путь рабочей папки задаётся через `WORK_DIR`. Относительное значение отсчитывается от каталога `WEB_STTV`/продукта; допускается абсолютное внутри репозитория. Изменение настройки не перемещает существующие данные. В корневой `.gitignore` добавлено `/WEB_STTV/data/`; другую рабочую папку при необходимости исключают отдельно. Настройка применяется при каждом запуске сборщика.

Исходники читаются непосредственно из выбранных каталогов в режиме read-only. Результат парсинга сохраняется в JSON для последующего обогащения; копии исходных файлов не создаются. Для перестроения нужны источники, для чтения готовой базы — нет.

## Глобальные переменные

Общий файл [global_variables.json](global_variables.json) хранит уже определённые переменные проекта. Он пополняется по мере появления новых переменных для любых частей приложения; его назначение не ограничено парсингом.

| Переменная | Назначение | Текущее значение |
| --- | --- | --- |
| `WORK_DIR` | Рабочая папка продукта и проверок, по умолчанию относительно каталога проекта | `data` |
| `STELLARIS_ROOT` | Абсолютный путь к корню установленной игры | `E:/SteamLibrary/steamapps/common/Stellaris` |
| `TECH_PATH` | Путь к каталогу технологий относительно `STELLARIS_ROOT` | `common/technology` |
| `INLINE_SCRIPTS_DIR` | Каталог шаблонов `inline_script` относительно `STELLARIS_ROOT` | `common/inline_scripts` |
| `WORKSHOP_DIR` | Абсолютный путь к модам Stellaris из Steam Workshop | `E:/SteamLibrary/steamapps/workshop/content/281990` |
| `RU_LOC_TIER_1` | Русская локализация, высший приоритет: `replace` мода Russian Localization Fix RE | `${WORKSHOP_DIR}/681483874/localisation/replace` |
| `RU_LOC_TIER_2` | Русская локализация, второй приоритет: каталог `russian` того же мода | `${WORKSHOP_DIR}/681483874/localisation/russian` |
| `RU_LOC_TIER_3` | Русская локализация, третий приоритет: ванильная, относительно `STELLARIS_ROOT` | `localisation/russian` |
| `EN_LOC_TIER_1` | Английская локализация: ванильная, относительно `STELLARIS_ROOT` | `localisation/english` |

Пути `TECH_PATH`, `INLINE_SCRIPTS_DIR`, `RU_LOC_TIER_3` и `EN_LOC_TIER_1` отсчитываются от `STELLARIS_ROOT`. Запись `${WORKSHOP_DIR}` в двух остальных путях обозначает подстановку значения одноимённой переменной. Это соглашение файла настроек: JSON хранит обычные строки и сам подстановку не выполняет. В путях используются прямые слеши `/`, как и в ранее заданных переменных.

`INLINE_SCRIPTS_DIR` используется для раскрытия вставок. Например, `script = technologies/rare_technologies_weight_modifiers` указывает на `STELLARIS_ROOT/INLINE_SCRIPTS_DIR/technologies/rare_technologies_weight_modifiers.txt`. Каталог доступен только для чтения; шаблоны загружаются по достигнутым вызовам, включая вложенные.

Вложенные вызовы, подстановка аргументов и история вставок реализованы. Метаданные исключены из аналитического обхода; актуальное представление описано в [руководстве шестого этапа](Docs/BACKEND_STAGE_6_RU.md).

Русский текст для каждого ключа выбирается в порядке `RU_LOC_TIER_1` → `RU_LOC_TIER_2` → `RU_LOC_TIER_3`, с переходом к следующему источнику при отсутствии ключа. Английский текст того же ключа берётся из `EN_LOC_TIER_1`. Русская и английская локализации рассматриваются отдельно; наличие ключей в обоих языках проверяется независимо.

Абсолютные корни источников относятся к текущему окружению. Каталоги игры и локализации доступны только для чтения; `WORK_DIR` предназначен для записи результатов. Сборщик загружает переменные и раскрывает inline-вставки. Каталоги локализации ему не требуются; получение названий относится к будущему обогащению.
