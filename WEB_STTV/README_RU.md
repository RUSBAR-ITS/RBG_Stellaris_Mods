## Проект

**Stellaris Technological Tree View**, каталог проекта — `WEB_STTV`.

Локальный интерактивный веб-справочник по технологиям Stellaris. Основной режим — дерево связей из карточек технологий с ванильными изображениями. Данные собираются из выбранных пользователем источников и преобразуются во внутреннюю базу справочника. Предполагается переносимая поставка для Windows без отдельной установки веб-сервера.

## Статус

На 2026-11-15 реализован утверждённый [первый этап бэкэнда](Docs/TZ_RU.md#3-первый-этап-бэкэнда--сборка-бд): самостоятельный Python-сборщик со строгой JSON-моделью, названиями RU/EN, проверками и отдельным отчётом. На текущих источниках собраны 679 технологий и 206 вариантов; все 885 записей имеют названия на обоих языках. Пройдены 29 синтетических проверок. [Запуск, устройство и результаты проверок](Docs/BACKEND_STAGE_1_RU.md).

Перед дальнейшим проектированием выполнено [исследование технологического древа](Docs/RESEARCH_TECH_TREE_RU.md) установленной Stellaris v4.5.4: определения, логические связи, уровни, условия доступа, варианты и повторяемость. Результаты исследования не являются новой утверждённой частью ТЗ.

Код сборщика находится в `src/backend/`, проверенная база — в `data/database.json`. Интерфейс, HTTP-служба, изображения и portable-поставка ещё не реализованы; версия программного выпуска не назначена. Для следующих этапов согласованы TypeScript, HTML/CSS и PyInstaller в режиме `onedir`. Исследовательский аудит остаётся в `TMP/WEB_STTV/` и не является входом продукта.

## Структура каталога

| Путь | Назначение |
| --- | --- |
| `src/frontend/` | Код интерфейса |
| `src/backend/` | Код Python для обработки и последующей служебной части |
| `config/` | Профили чтения, приоритеты и пути результатов сборки |
| `schemas/` | Строгие схемы JSON и реестр поддерживаемых скриптовых команд |
| `data/` | Рабочая папка по умолчанию для БД, отчётов, временных результатов и проверок |
| `Docs/` | Документация на русском и английском |

Путь рабочей папки задаётся через `WORK_DIR`. Относительное значение отсчитывается от каталога `WEB_STTV`/продукта; допускается абсолютное. Изменение настройки не перемещает существующие данные. В корневой `.gitignore` добавлено `/WEB_STTV/data/`; другую рабочую папку при необходимости исключают отдельно. Настройка применяется при каждом запуске сборщика.

Исходники читаются непосредственно из выбранных каталогов в режиме read-only. Копии исходных файлов и постоянный промежуточный снимок не создаются; разбор и преобразование работают с данными в памяти. Для перестроения нужны источники, для чтения готовой базы — нет.

## Глобальные переменные

Общий файл [global_variables.json](global_variables.json) хранит уже определённые переменные проекта. Он пополняется по мере появления новых переменных для любых частей приложения; его назначение не ограничено парсингом.

| Переменная | Назначение | Текущее значение |
| --- | --- | --- |
| `WORK_DIR` | Рабочая папка продукта и проверок, по умолчанию относительно каталога проекта | `data` |
| `STELLARIS_ROOT` | Абсолютный путь к корню установленной игры | `E:/SteamLibrary/steamapps/common/Stellaris` |
| `TECH_PATH` | Путь к каталогу технологий относительно `STELLARIS_ROOT` | `common/technology` |
| `WORKSHOP_DIR` | Абсолютный путь к модам Stellaris из Steam Workshop | `E:/SteamLibrary/steamapps/workshop/content/281990` |
| `RU_LOC_TIER_1` | Русская локализация, высший приоритет: `replace` мода Russian Localization Fix RE | `${WORKSHOP_DIR}/681483874/localisation/replace` |
| `RU_LOC_TIER_2` | Русская локализация, второй приоритет: каталог `russian` того же мода | `${WORKSHOP_DIR}/681483874/localisation/russian` |
| `RU_LOC_TIER_3` | Русская локализация, третий приоритет: ванильная, относительно `STELLARIS_ROOT` | `localisation/russian` |
| `EN_LOC_TIER_1` | Английская локализация: ванильная, относительно `STELLARIS_ROOT` | `localisation/english` |

Пути `TECH_PATH`, `RU_LOC_TIER_3` и `EN_LOC_TIER_1` отсчитываются от `STELLARIS_ROOT`. Запись `${WORKSHOP_DIR}` в двух остальных путях обозначает подстановку значения одноимённой переменной. Это соглашение файла настроек: JSON хранит обычные строки и сам подстановку не выполняет. В путях используются прямые слеши `/`, как и в ранее заданных переменных.

Русский текст для каждого ключа выбирается в порядке `RU_LOC_TIER_1` → `RU_LOC_TIER_2` → `RU_LOC_TIER_3`, с переходом к следующему источнику при отсутствии ключа. Английский текст того же ключа берётся из `EN_LOC_TIER_1`. Русская и английская локализации рассматриваются отдельно; наличие ключей в обоих языках проверяется независимо.

Абсолютные корни источников относятся к текущему окружению. Каталоги игры и локализации доступны только для чтения; `WORK_DIR` предназначен для записи результатов. Загрузка переменных, подстановка ссылок и подбор названий реализованы в сборщике.
