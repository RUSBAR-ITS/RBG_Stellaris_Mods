## Пересборка

25 ноября 2026 года стенд обновлён с 4.5.4 до Corona Borealis 4.6.0 (3d1a). До удаления `wiki` загрузчик проверил состав экспорта, идентификаторы и размеры BSON. После полного сброса загружены 359 322 документа в 110 коллекций импорта. Повторное чтение из MongoDB подтвердило совпадение с JSON, включая восстановление деревьев с исходными позициями. Загрузка заняла 645,62 с, независимая сверка 565,01 с. Передача изображений и сверка их хешей заняли 30,66 с. Переданы четыре значка технологий и обложка Willpower.

| Объекты | 4.5.4 | 4.6.0 |
|---|---:|---:|
| Технологии | 679 | 683 |
| DLC в каталоге | 36 | 37 |
| События | 10 111 | 10 504 |
| Записи локализации RU и EN | 306 310 | 316 303 |

Парсер собрал пять библиотек из 818 файлов и обработал 845 файлов профиля. В новом DLC потребовались три согласованных исключения. Восстановлен пропущенный знак присваивания у `increase_pop_political_power`, семи подстановкам внутри `move_galactic_halls` задано умолчание `no` при отсутствии аргумента, во вложенный шаблон `council_no` передан класс из вызывающей черты. Все 18 тестов парсера прошли. [Правила исключений](../../Instruments/Stellaris_Parser/stellaris_parser/config/source_exceptions.json)

## Перепроверка исключений парсера

Каждое из восьми правил `source_exceptions.json` отключалось отдельно в памяти при разборе всех перечисленных для него файлов 4.6.0. Отдельно проверен путь к inline-файлу без расширения. Таблица показывает число срабатываний обработчика за разбор и результат отключения.

| Участок | Результат на 4.6.0 |
|---|---|
| Занятость, `06_event_jobs.txt` | Одна ссылка с лишним завершающим разделителем. Ошибка разбора на строке 2176. |
| Реликвии, `RELIC` из `SELECTED_RELIC` | По 15 подстановок в `grand_archive_events.txt` и `leviathans_events_1.txt`. Без правила оба файла останавливаются на отсутствующем аргументе. |
| Кочевники, `RANDOM = 0` | Девять подстановок. Без правила у эффекта отсутствует аргумент `RANDOM`. |
| Метаданные `dlc002` | Одна вставка `=`. Без неё разбор заканчивается успешно, но имя `paradoxplaza_store_url` и пустая строка становятся двумя отдельными значениями. |
| Черты, `trait/icon` | 55 подстановок в 5 из 13 разрешённых файлов. В остальных восьми отключение даёт идентичный документ. |
| Черты, `trait/icon_element/council_no` | 63 подстановки в 11 из 11 файлов. Две относятся к файлу Willpower. |
| Традиция `tr_purity_imperfection_remediation_wilderness` | Имя файла всё ещё без `.txt`. Без явного пути `01_purity.txt` завершается ошибкой поиска шаблона. |
| Новые правила Willpower | Без исправления `increase_pop_political_power` библиотека останавливается на строке 1879. В `move_galactic_halls` обработчик восполняет один отсутствующий аргумент. Без правила разбор останавливается на строке 2667. |

Список для **внешнего** шаблона `trait/icon` можно сократить на восемь файлов из `common/traits/`. Это `00_admiral_traits.txt`, `00_general_traits.txt`, `00_generic_leader_traits.txt`, `00_governor_traits.txt`, `00_scientist_traits.txt`, `08_ancrel_traits.txt`, `15_biogenesis_leader_traits.txt` и `16_infernals_traits.txt`. История раскрытия в экспортах 4.5.4 и 4.6.0 подтверждает одинаковое количество вызовов без явно переданного класса в каждом из 13 файлов, в этих восьми — ноль в обеих версиях. Для вложенного `council_no` требуется весь его список. ## Дерево и страницы

Проверены десять комбинаций DLC, смешанных деревьев и фильтра событийных технологий. Сверены связи родитель–ребёнок, отсутствие циклов, уникальность ячеек RU/EN и повторное открытие сохранённых деревьев. Справочник показывает 682 карточки со всеми DLC, 678 при отключении только Willpower, 468 при включении только Willpower и 464 без DLC. При всех DLC условие `has_ancrel = no` исключает `tech_archeology_lab`.

В Chrome проверены 1 366 страниц. Заголовки, секции, условия и значки совпали с ответами API. На «Синих лазерах» совпало также содержимое карточки и самостоятельной страницы при раскрытии награды с клавиатуры. Проверка старых адресов наград отметила 1 038 языковых страниц. При сравнении по игровому источнику и содержанию награды у 679 прежних технологий сохранились все группы источников и все ранее показанные результаты выдачи. У 262 добавились источники. ## Пробелы в данных и тексте

| Где проявляется | Что показала проверка |
|---|---|
| Кризисные бонусы Willpower | Вне профиля импорта остался `common/menace_perks`. Бонус второго уровня кризиса выдаёт изученную `tech_cultural_envoys`. Бонус пятого уровня содержит шесть команд начисления 50% прогресса для прыжкового двигателя и вариантов маскировки. Для маскировки важны условие First Contact и ветки `inverted_switch`. |
| Принцип идеологии юутов | Вне профиля остался `common/ideologies/tenets`. При открытии `tenet_lost_makers_yuht` становится доступна для исследования `tech_ecological_adaptation`, если технология ещё не изучена. |
| Заголовок культурных послов | Вики показывает «значение из текущей игры». Для `GetCulturalEnvoyNamePlural` в `common/scripted_loc/16_scripted_loc_forceofwill.txt` есть три условных перевода и явный `default = cultural_envoy_default_plural`. В справочнике можно использовать дефолт «Культурные послы» / «Cultural Envoys». |
| Источники и условия идеологий | На 261 технологии нет подписи действия `on_ideology_momentum_positive`; на 261 появилась нераспознанная проверка `num_active_tenets`. Ещё четыре технологии требуют описания области `ideology?`, одна — сравнения `free_building_slots`. Эти группы пересекаются. |
| Галактические залы | У типа государства `rebel` не подставлено название. В блоке веса указан `mult = 2`; рендерер выдаёт частичное условие. Для поддержки этого синтаксиса в весе технологии требуется отдельно подтвердить его игровую семантику. |
| Отдельные награды и отметки | У «Псионической теории» остаются две общие подписи флагов `lost_makers_precursor_zroni` и `lost_makers_precursor_adakkaria`. У стабилизации червоточин остаётся общая подпись `event_target:selected_precursor_system`. Для «Идеологической проекции» смысл `unlock_tech_ideology_projection` пока описывается через действия, устанавливающие флаг. |

Аудит выделил 265 технологий с хотя бы одной из проверяемых проблем читаемости на каждом языке. Отдельная проверка нашла динамическую подпись на 262 технологиях. Основной пример — заголовок события `forceofwill.1560`, в котором игра подставляет название догмата конкретной империи. На всех 1 366 страницах проверка прошла без утечек игровой разметки. Выводы о наградах основаны на игровых скриптах и опубликованных страницах.
