## Запуск и открытие

Реализовано [ТЗ этапа 10](TZ_FRONTEND_STAGE_10_RU.md), расчёты выполняет [бэкенд этапа 20](../BACKEND_STAGE_20_RU.md). Из корня репозитория запустить сервис в отдельном терминале:

```powershell
$env:PYTHONPATH = (Resolve-Path WEB_STTV/src/backend).Path
WEB_STTV/data/.venv/Scripts/python.exe -X utf8 -B -m sttv.service
```

Во втором терминале:

```powershell
$env:PATH = (Resolve-Path WEB_STTV/data/frontend-tools/node-v24.22.3-win-x64).Path + ';' + $env:PATH
npm.cmd --prefix WEB_STTV run dev
```

Открыть `http://127.0.0.1:5173/`, нажать «Открыть набор БД» и выбрать **`WEB_STTV/data/stage20/database_set`**. Этот каталог зарегистрирован текущим `config/service.json`. Подготовка уже выполнена; запускать сборщик не требуется.

После явного открытия используется комбинация со всеми включёнными DLC. При недоступном сервисе можно просматривать уже подготовленную подходящую комбинацию; применение настроек недоступно. Несовпадение выбранного набора с настройками сервиса показывается отдельно. После запуска сервиса повторно открыть каталог.

## Работа с настройками

В меню появились «Древо технологий» и «Настройка DLC». Переход сохраняет набор, положение поля, масштаб и черновик настроек. Свёрнутое меню сохраняет прежнюю узкую полосу; выбор раздела доступен после раскрытия.

Список DLC сортируется по названию текущего языка. Слева показана миниатюра либо заглушка, справа — переключатель и подпись состояния. Переключатель работает мышью, Space и Enter. Его доступное имя — название дополнения. Названия переносятся без многоточия.

Переключатели меняют черновик. «Применить» отправляет весь выбор одним запросом; «Сбросить изменения» возвращает действующий профиль. Во время расчёта доступны переход между разделами и отмена, переключатели заблокированы. До успеха показывается прежнее дерево. Ошибка и отмена сохраняют его вместе с черновиком; причина попадает в сохраняемый отчёт.

После успеха видимость, родители, дети, сетка и связи заменяются согласованно. Положение просмотра ограничивается новой геометрией. Смена языка, темы и масштаба не меняет выбор DLC. Обновление страницы не открывает БД, не запускает сборку и не восстанавливает настройки автоматически.

## Реализация

| Область | Файлы |
| --- | --- |
| Вид и черновик | `views/DlcSettings.tsx`, `app/useDlc.ts` |
| UI-кит | `ui/base/Switch.tsx`, `ui/composite/DlcRow.tsx`, навигационное состояние `Button` |
| Настройки и оформление | `config/frontend/dlc.json`, `styles/elements.css`, `views/dlc-settings.css`, `locales/ru.json`, `locales/en.json` |
| Сервис и байты | `storage/api.ts`, `storage/bytes.ts`, `storage/reader.ts` |
| Снимок и адаптер | `storage/session.ts`, `data/setAdapter.ts`, `workers/dlc.ts`, протокол Worker |

Геометрия списка/переключателя задана конфигом, цвета и шрифты — именованными переменными для обеих тем. Полный AST и доказательства DLC остаются на бэкенде; интерфейс использует компактные результаты и отчёт. Он не дублирует вычислитель игровых условий.

При обновлении снимка перечитываются только изменившиеся документы технологий. Неизменившиеся каталоги и изображения переиспользуются. Новые байты читаются из API потоком с проверкой хеша; применение завершается только после подготовки всего нового каталога. Поздний ответ другой операции или ревизии не заменяет текущий экран.

## Проверки

Проверка типов и производственная сборка прошли. Модульные проверки: 69 пройдены, 3 зависящие от окружения пропущены. Браузерные проверки: 32 сценария пройдены с учётом повторного запуска исправленных сценариев; отдельная нагрузочная проверка файла размером 512 МиБ пропущена. На реальном наборе проверены обе темы, миниатюры, связи и переход «все DLC → ни одного → все».

Проверяются черновик без пересчёта, сброс, применение нескольких переключателей одним запросом, отмена, ошибка, сохранение прежнего дерева, обновление документов через API и отсутствие автоматического открытия после перезагрузки страницы. Отдельные проверки контролируют чтение только изменившегося файла, сохранение каталога DLC и отказ при повреждении новых байтов.

Реальные контрольные профили: 678 видимых технологий при всех DLC, 543 без DLC, 544 при `dlc002` и `dlc036`. Выключение дополнений может также открыть технологию с отрицательным DLC-условием. Исходные 679 объектов остаются в БД.

Журналы находятся в `data/stage20/`, снимки интерфейса — `data/stage20/screenshots/`. Браузерные сценарии используют Chromium и локальный Python-сервис; тесты игровых условий не заменяют их выполнение в движке.

## Ограничения

Косвенные DLC-ограничения через определения других объектов пока не вычисляются. Например, требование биологических кораблей оставляет оружие ткачей видимым без BioGenesis. Это подтверждённый пробел покрытия; предложенное расширение описано в [проекте этапа 21](../TZ_BACKEND_STAGE_21_RU.md). Числа видимых технологий выше относятся к фильтру этапа 20.

Это настройка справочника, а не определение купленных дополнений. Неизвестные игровые условия не исключают технологию. Базовый нулевой вес сам по себе не скрывает карточку. Варианты берутся из подготовленной комбинации; автоматический выбор по империи и интерактивное переключение вариантов не добавлены. Настройки между запусками пока не сохраняются.
