## Назначение и состав

Страница технологии — самостоятельный вид в `views/` для чтения подробностей одной базовой технологии. Заголовком служит полное локализованное название, под ним располагается описание. Далее идут требуемые технологии, условия доступности, изменения веса выпадения и разделы получения, для которых есть подтверждённые источники. Порядок и правила показа этих разделов заданы в [ТЗ этапа](../TZ_TECHNOLOGY_PAGE_AND_ACQUISITION_RU.md#три-раздела-получения).

Страница и тултип используют один ответ API и общие компоненты для вывода подробностей. При одинаковом языке и выборе DLC совпадают тексты, группы условий, цвета, игровые иконки, проценты и формулы. Длинное содержимое прокручивается вместе со страницей.

## Открытие и возврат

Страница имеет собственный адрес с игровым ID. Предлагаемый адрес для стенда — `/#/technology/tech_ordered_retreat`. Пункт контекстного меню карточки открывает страницу в текущей вкладке, средняя кнопка мыши открывает её в новой вкладке. Ссылка из дерева передаёт язык и применённый выбор DLC, включая пустой набор. При отсутствии этих параметров действуют настройки справочника по умолчанию.

При прямом переходе и обновлении браузера приложение запрашивает подробности по ID. Открытие страницы не требует загрузки дерева или расчёта координат. При переходе из дерева в той же вкладке кнопка браузера «Назад» возвращает к прежней позиции. Для неизвестного ID выводятся локализованное сообщение и ссылка на дерево.

## Проверка

Сравнить страницу и тултип одной технологии на RU и EN с одинаковым набором DLC. Проверить длинное описание, составные условия, наличие и отсутствие источников получения. Проверить переход из карточки, возврат, новую вкладку, прямую ссылку после обновления браузера и неизвестный ID. Для ссылки без настроек и ссылки с явно отключёнными всеми DLC проверить соответствующие отметки у источников.
