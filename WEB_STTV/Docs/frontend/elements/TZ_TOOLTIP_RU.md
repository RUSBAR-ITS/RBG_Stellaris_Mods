## Статус и назначение

Документ фиксирует текущий набор требований, согласованный пользователем 2026-11-16. Будущие расширения будут обсуждаться отдельно. Реализация элемента ещё не начата.

«Тултип» — общий переиспользуемый элемент для подсказок кнопок и названий с описаниями технологий. Основа — [концепт интерфейса](../CONCEPT_RU.md) и [список UI-элементов](../UI_ELEMENTS_RU.md).

## Состав и входные настройки

Содержимое состоит из основного текста и необязательного заголовка над ним. Обе части отображаются через базовый элемент [«Текст»](TZ_TEXT_RU.md) со своими ролями оформления. Использующий компонент передаёт источник, ID основной строки, при наличии заголовка — ID его строки, а также элемент привязки. Источник по умолчанию встроенный; карточка технологии использует БД. Источник и соответствующий ID передаются в каждый элемент «Текст», а язык предоставляет система.

| Данные или настройка | Назначение |
| --- | --- |
| Источник, необязательный | Встроенные строки по умолчанию либо БД приложения |
| Идентификатор основной строки | Ключ основного текста подсказки для элемента «Текст» |
| Идентификатор заголовка, необязательный | Ключ отдельной строки над основным текстом |
| Элемент привязки | Элемент интерфейса, относительно которого размещается тултип |
| Условие видимости | Определяет, требуется ли сейчас показывать подсказку |
| Роль оформления | Переменные словаря для оформления тултипа и его текста |

Таблица описывает необходимые сведения, а не окончательные имена программных параметров или способ их передачи.

Если заголовок не задан, выводится только основной текст. Для карточки технологии заголовок содержит полное название, основной текст — описание; ограничение названия в карточке двумя строками не применяется к тултипу.

## Показ и скрытие

Тултип имеет состояния «скрыт» и «показан». Условие видимости определяется использующим компонентом; общие правила размещения и оформления принадлежат тултипу.

- Для кнопки условия наведённого указателя, клавиатурного фокуса и отсутствия подсказки определены в [ТЗ кнопки](TZ_BUTTON_RU.md#связь-с-тултипом).
- Для [карточки технологии](TZ_TECHNOLOGY_CARD_RU.md) показываются название и описание при наведении на любую её часть, включая внутренние отступы; при уходе указателя тултип скрывается.

Тултип используется как один общий вид UI-элемента; его правила не копируются в отдельные реализации для каждого потребителя.

## Размещение и оформление

- Тултип размещается возле элемента привязки поверх содержимого интерфейса.
- Появление и скрытие не сдвигают карточки, кнопки и другие элементы.
- Позиция учитывает границы видимой области: подсказка не должна обрезаться из-за размещения за её краем.
- Для кнопок [нижней группы меню](TZ_MENU_BUTTON_GROUP_RU.md) тултип может выходить за границы группы и панели без обрезания, оставаясь в видимых границах окна, в том числе при свёрнутой панели.
- В [рабочей области технологий](TZ_TECHNOLOGY_VIEWPORT_RU.md) границы прокручиваемого контейнера также не обрезают тултип; он остаётся в видимых границах окна и не влияет на размеры поля, диапазоны или появление полос прокрутки.
- Цвета фона, границы и текста, а также параметры шрифта задаются через [словарь оформления](../CONCEPT_RU.md#словарь-цветов-и-шрифтов) с учётом дневной или ночной темы.
- Правила размещения и оформления общие для всех применений тултипа; конкретное содержимое и элемент привязки поступают от потребителя.

## Критерии приёмки

Проверки выполняются после реализации:

- Основной текст и заданный заголовок получаются по источнику и соответствующим ID через общий элемент «Текст» и обновляются при смене RU/EN; проверяются встроенная подсказка по умолчанию и строки из БД.
- Без заголовка отображается только основной текст; при его наличии заголовок находится над основным текстом и использует собственную роль оформления.
- Переходы между состояниями «показан» и «скрыт» соответствуют условию видимости потребителя.
- Один общий элемент используется для подсказки кнопки и названия с описанием технологии; название, сокращённое в карточке, полностью доступно в тултипе.
- Показ и скрытие не меняют размеры и расположение остальных элементов.
- Проверено размещение возле каждого края видимой области; тултип остаётся в её границах.
- Подсказки нижних кнопок меню не обрезаются границами группы или панели в раскрытом и свёрнутом состояниях.
- Тултипы карточек возле границ рабочей области не обрезаются прокручиваемым контейнером и не меняют размеры поля, диапазоны или появление полос прокрутки.
- Обе темы применяют цвета и шрифтовые параметры из словаря.
- Для кнопки выполнены сценарии видимости из её ТЗ, включая отсутствие заданной подсказки.

## Детали последующей реализации

Конкретные имена параметров и переменных, способ привязки, предпочтительная сторона размещения, отступы и допустимые размеры определяются при проектировании реализации. Обработка текста, превышающего доступную область, также должна быть определена на этом этапе.
