## Статус и назначение

Документ фиксирует текущий набор требований, согласованный пользователем 2026-11-16, включая необязательные текст и иконку, настройку границы и привязку к общему тултипу. Будущие расширения будут обсуждаться отдельно. Реализация элемента ещё не начата.

«Кнопка» — общий элемент для действий интерфейса. Пункты меню, сворачивание панели и переключение темы могут использовать этот элемент. Основа — [концепт интерфейса](../CONCEPT_RU.md) и [список UI-элементов](../UI_ELEMENTS_RU.md).

## Состав и входные настройки

Кнопка использует элементы [«Текст»](TZ_TEXT_RU.md), [«Иконка»](TZ_ICON_RU.md) и при наличии подсказки — [«Тултип»](TZ_TOOLTIP_RU.md).

Для каждой текстовой подписи, названия действия и подсказки вместе с идентификатором можно передать источник по ТЗ текста. По умолчанию используются встроенные интерфейсные строки; при явно выбранном источнике БД поиск выполняется в нём. Кнопка передаёт источник вместе с идентификатором общему механизму локализации.

| Данные или настройка | Назначение |
| --- | --- |
| Идентификатор строки, необязательный | Ключ видимой подписи для элемента «Текст» |
| Иконка, необязательная | Символ из общего набора |
| Действие | Действие, назначенное использующим компонентом |
| Размеры, отступы и расположение содержимого | Компоновка кнопки |
| Роль оформления | Переменные словаря по назначению и состоянию |
| Видимость границы по состояниям | Видимая или скрытая декоративная граница |
| Идентификатор названия действия для средств доступности | Ключ локализованного имени; может совпадать с ключом видимой подписи |
| Привязка к тултипу, необязательная | Идентификатор строки подсказки для общего элемента «Тултип» |

Таблица описывает необходимые сведения, а не окончательные имена программных параметров или способ их передачи. Поддерживаются применения с текстом, с иконкой и с их сочетанием.

## Компоновка и граница

Размеры, отступы и расположение содержимого задаёт использующий компонент. Активная область охватывает всю кнопку, включая внутренние отступы.

Граница может быть видимой или скрытой в зависимости от состояния. Например, пункт меню может показывать её только при наведении. Изменение видимости границы не меняет размер кнопки и не сдвигает содержимое.

## Состояния и оформление

Поддерживаются обычное состояние, наведение, фокус и нажатие. Цвета фона, границы, текста и иконки, а также шрифтовые параметры подписи назначаются через [словарь оформления](../CONCEPT_RU.md#словарь-цветов-и-шрифтов) с учётом темы и состояния.

«Текст» и «Иконка» используют оформление для состояния содержащей их кнопки. Клавиатурный фокус остаётся различимым при скрытой декоративной границе; её видимость не заменяет обозначение фокуса.

## Активация и доступность

Поддерживаются активация мышью и клавиатурой. Одна активация вызывает назначенное действие один раз, в том числе при нажатии на текст, иконку или внутренние отступы. Смысл действия определяется использующим компонентом.

Видимая подпись может служить названием действия для средств доступности. Для кнопки без текста идентификатор локализованного названия передаётся отдельно. Все строки, включая название для средств доступности, получаются общим механизмом локализации по текущему языку приложения.

## Связь с тултипом

Кнопка использует общий элемент [«Тултип»](TZ_TOOLTIP_RU.md); правила его размещения и оформления определены в отдельном ТЗ.

- Если подсказка не задана, тултип не появляется.
- Если подсказка задана, тултип показывается при наведении на кнопку **или** при её клавиатурном фокусе.
- Тултип скрывается, когда оба условия отсутствуют. Уход указателя при сохранённом клавиатурном фокусе не скрывает подсказку; потеря фокуса при сохранённом наведении также не скрывает её.
- Элементом привязки служит сама кнопка. Идентификатор строки подсказки поступает от использующего компонента.

## Критерии приёмки

Проверки выполняются после реализации:

- Отображаются варианты с текстом, с иконкой и с их сочетанием через соответствующие базовые элементы.
- Размеры, отступы и расположение содержимого соответствуют настройкам потребителя.
- Видимая и скрытая граница, включая её изменение при наведении, сохраняют размер кнопки и положение содержимого.
- В обычном состоянии, при наведении, фокусе и нажатии применяются назначенные переменные обеих тем.
- Клавиатурный фокус различим при скрытой границе.
- Активация мышью по содержимому и отступам, а также активация клавиатурой вызывают действие один раз.
- Подпись, название действия для средств доступности и подсказка получаются по идентификаторам и обновляются при смене языка.
- Без заданной подсказки тултип отсутствует. С подсказкой проверены наведение, фокус, их сочетание и исчезновение обоих условий.

## Детали последующей реализации

Конкретные имена параметров и переменных, размеры, правила расположения текста и иконки и способ оформления фокуса определяются при проектировании реализации. Роль кнопки в меню и конкретные действия закрепляются в ТЗ использующих компонентов.
