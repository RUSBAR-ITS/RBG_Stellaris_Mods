## Статус и назначение

Документ фиксирует текущие требования, согласованные пользователем 2026-11-16. На первом этапе элемент представляет собой выпадающий список с выбором одного варианта. Реализация элемента ещё не начата.

Основа — [концепт интерфейса](../CONCEPT_RU.md) и [список UI-элементов](../UI_ELEMENTS_RU.md). Конкретный набор вариантов и смысл выбранного значения определяются использующим компонентом. Первое применение описано в отдельном [ТЗ выбора языка](TZ_LANGUAGE_SELECTOR_RU.md).

## Содержимое и входные настройки

| Данные или настройка | Назначение |
| --- | --- |
| Набор вариантов | Значения и идентификаторы строк подписей доступных вариантов |
| Текущее значение | Один выбранный вариант из переданного набора |
| Обработка выбора | Получение использующим компонентом результата выбора пользователя |
| Роль оформления | Именованные переменные для элемента и его вариантов по состояниям |

Таблица описывает необходимые сведения, а не окончательные имена программных параметров или способ их передачи.

Идентификаторы подписей и текущее значение поступают от использующего компонента. Подписи получаются общим механизмом локализации по языку приложения. Элемент сообщает выбранное значение потребителю, который определяет дальнейшее действие. Значение варианта и идентификатор его подписи — разные данные; смена языка меняет подпись, сохраняя значение.

Вместе с идентификатором подписи можно передать источник согласно [ТЗ текста](TZ_TEXT_RU.md). По умолчанию источник встроенный, также поддерживается БД; источник передаётся общему механизму локализации вместе с идентификатором.

## Отображение и выбор

- В закрытом состоянии отображается подпись текущего выбранного варианта.
- Раскрытие показывает переданный набор вариантов в выпадающем списке.
- Одновременно выбирается один вариант.
- Поддерживаются управление и выбор мышью и клавиатурой.
- При выборе пользователем варианта его значение передаётся использующему компоненту.
- Отображаемый выбор соответствует текущему значению, предоставленному потребителем.

Отображение подписей по идентификаторам следует общим требованиям к [элементу «Текст»](TZ_TEXT_RU.md). Функциональное назначение выбора задаётся составным компонентом, который использует список.

Раскрытый список отображается поверх содержимого по [ТЗ основного окна](TZ_MAIN_WINDOW_RU.md#всплывающие-элементы), учитывает его видимые границы и не обрезается вложенными контейнерами. Его показ не меняет размеры основной раскладки или диапазоны прокрутки поля.

При использовании в [карточке технологии](TZ_TECHNOLOGY_CARD_RU.md#работа-со-списком-вариантов) роль закрытого элемента и элемента открытия выполняет сама карточка. Её название следует ТЗ карточки; подписи пунктов списка включают согласованные суффиксы вариантов. Порядок пунктов, подтверждение и отмена, клавиатурные команды и скрытие тултипа для этого применения определены в ТЗ карточки и реализуются через общий элемент выбора.

## Состояния и оформление

Оформление предусматривает обычное состояние, наведение, фокус и выбранный вариант. Выбранное значение и положение фокуса — отдельные характеристики; оформление должно позволять различать их.

Цвета фона, границ и текста, а также шрифтовые параметры назначаются через именованные переменные [словаря оформления](../CONCEPT_RU.md#словарь-цветов-и-шрифтов) для действующей темы и соответствующего состояния. Это правило распространяется на закрытый элемент и варианты раскрытого списка.

## Критерии приёмки

Проверки выполняются после реализации:

- Переданный набор вариантов отображается с подписями, полученными по идентификаторам; в закрытом состоянии видна подпись текущего значения.
- Выбор одного варианта мышью и клавиатурой передаёт его значение использующему компоненту.
- Одновременно выбран один вариант, соответствующий текущему значению потребителя.
- Изменение текущего значения извне отражается в элементе.
- Смена языка обновляет подписи через общий механизм локализации, сохраняя значения вариантов и текущий выбор.
- Обычное состояние, наведение, фокус и выбранный вариант используют соответствующие переменные словаря в обеих темах.
- Выбранный вариант и фокус различимы при работе со списком.
- Раскрытый список возле границ окна виден поверх содержимого без обрезания вложенными контейнерами и без изменения основной раскладки или диапазонов прокрутки поля.

## Детали последующей реализации

Конкретные имена параметров и переменных, размеры, способ реализации выпадающего списка и клавиатурные команды, ещё не закреплённые в ТЗ использующего компонента, определяются при проектировании реализации. Поведение для пустого набора или отсутствующего в нём текущего значения также требует определения на этом этапе.
