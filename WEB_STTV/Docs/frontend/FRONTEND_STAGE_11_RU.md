## Работа со справочником

Первое нажатие **Древо технологий** открывает справочник со всеми включёнными дополнениями. Возврат из настроек показывает уже открытое дерево. Загрузка страницы и переход по вкладкам сами по себе сборку не запускают. [Тестовый стенд](http://192.168.1.36:5173/)

В **Настройки игры → DLC** можно изменить несколько переключателей и нажать **Применить**. Черновик сохраняется при переходе на другую вкладку и смене языка. При ошибке сервер возвращает причину, а черновик доступен для повторного применения.

В **Настройки игры → Настройки империи** находится переключатель **Режим справочника**. По умолчанию он включён и блокирует секцию параметров империи. Выключение открывает секцию. Само дерево империи предусмотрено следующим этапом. До его появления вкладка DLC доступна в обоих режимах.

В **Настройки системы → Операции с БД** кнопка **Очистить построенные деревья** удаляет кэш всех комбинаций. После успешной очистки панель состояния показывает число удалённых коллекций. Следующее открытие использует применённый выбор DLC. [ТЗ](TZ_FRONTEND_STAGE_11_RU.md)

## Каталог DLC

Сервер читает каталог и дескрипторы из MongoDB. Для русского названия он строит ключ `sttv_<id>_name` и вызывает стандартный поиск локализации. Для английского названия и будущих DLC без проектного перевода он ищет игровой ключ и при его отсутствии использует название из каталога. Фронтенд получает обе подписи и сортирует строки по текущему языку. [Русский словарь](../../localization/russian/sttv_dlc_names_l_russian.yml) · [Контракт сервера](../../src/server/README_RU.md#дерево-технологий)

`thumbnail` содержит путь PNG относительно `/game-assets/` либо `null`. Строка дополнения с отсутствующей картинкой сохраняет подпись и переключатель. Фронтенд открывает дерево и читает данные карточек через HTTP. Импорт файлового набора, его worker и выгрузка отчёта удалены.

## Проверки

На тестовой VM проверены все 36 пар названий по утверждённой таблице и 36 отдельных ключей русской локализации. Браузер загрузил все 32 объявленные миниатюры. У четырёх дополнений миниатюра отсутствует.

| Применённый набор на VM | Видимые технологии |
|---|---:|
| Все 36 DLC | 678 |
| Все отключены | 464 |
| Только «Машинный век» | 504 |

Прошли проверка типов, производственная сборка, 14 модульных тестов фронтенда, 17 браузерных сценариев с рабочей станции и 17 серверных тестов на Ubuntu. На опубликованном дереве проверены карточки, изображения и связи. Сценарии ошибок и повторных нажатий проверены с управляемыми ответами API. Серверная проверка очистки использовала временные коллекции с отдельным префиксом.
