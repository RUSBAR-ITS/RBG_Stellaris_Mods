## Навигация

**Утверждённое ТЗ.** Цель этапа — привести интерфейс в соответствие с серверным режимом и подготовить место для настройки империи.

| Пункт меню | Содержимое основной области |
|---|---|
| Древо технологий | Дерево выбранного режима |
| Настройки системы | Вкладка «Операции с БД» |
| Настройки игры | Вкладки «DLC» и «Настройки империи» |

Панель вкладок — общий элемент UI-кита для обоих экранов. При первом входе активна первая вкладка. В пределах сеанса переход между экранами сохраняет выбранную вкладку и черновик DLC. Язык, тема, сворачивание меню, масштаб дерева и нижняя панель состояния сохраняют своё назначение. [Вкладки](elements/TZ_TABS_RU.md)

Открытие справочника — явное действие через «Древо технологий». При первом нажатии или после очистки клиент запрашивает дерево для применённого набора DLC. При возврате к уже открытому дереву показывает имеющийся результат. Загрузка страницы, переходы по настройкам и переключатель режима сами по себе сборку не запускают.

## Операции с БД

«Очистить построенные деревья» находится только на этой вкладке. Кнопка вызывает существующую операцию `DELETE /api/trees/reference`. После успеха клиент сбрасывает открытое дерево и показывает возвращённое число удалённых коллекций. Настройки DLC сохраняются. При ошибке клиент сохраняет дерево и выводит причину в панели состояния. Повторное нажатие во время запроса блокируется.

## Настройки игры

- **DLC.** При первом входе получить список с сервера. Изначально включены все DLC. Изменения накапливаются до «Применить», «Отменить изменения» восстанавливает последний применённый набор. В режиме справочника успешное применение обновляет дерево. Ошибка оставляет черновик доступным для повтора и сохраняет ранее применённый набор. В режиме империи применение сохраняет выбор DLC в сеансе. Последующее открытие справочника использует именно этот выбор.
- **Настройки империи.** Вверху разместить переключатель «Режим справочника», первоначально включённый. Пока он включён, все элементы ввода параметров империи внутри секции заблокированы для мыши и клавиатуры. Сам переключатель и вкладка DLC остаются доступны. При выключении снять блокировку. Состав отдельных параметров и расчёт дерева империи относятся к следующему этапу.
- **Древо технологий при выключенном справочнике.** Показать сообщение «Дерево империи ещё не реализовано». Ранее открытый справочник в этом режиме скрыт. Изменение режима во время запроса не должно приводить к показу ответа в чужом режиме.

## Названия DLC

Для всех 36 DLC текущего каталога подготовлен проектный русский перевод. Каждому игровому ID соответствует ключ `sttv_<id>_name`. Например, `dlc032` использует `sttv_dlc032_name`, который ссылается на игровую строку `$machine_age$` и отображается как «Машинный век». Для английского языка используются названия игры. [Русский словарь DLC](../../localization/russian/sttv_dlc_names_l_russian.yml)

У 10 из 14 названий в словаре лаунчера `pdx_launcher/common/localisation/dlc_l_russian.yml` русский текст отличается от английского. Этот словарь, описания дополнений и игровая локализация служат источниками для перевода. Там, где игра уже содержит подходящее название, словарь проекта ссылается на игровой ключ. Сюжетные наборы, наборы рас и отдельные портреты различаются в подписи. Например, `Infernals Species Pack` — «Набор рас „Термофилы“» по игровому классу `INF_plural`. Для `Vipra the Vapor` выбран образ существа из тумана. [Описание издателя](https://store.steampowered.com/app/4241410/)

1. После утверждения подключить каталог словаря к русским источникам в профиле подготовки и публиковать вместе с остальной локализацией штатным загрузчиком. Каждая строка создаёт отдельный документ в `wiki.localization`, например `_id = {"language":"ru","key":"sttv_dlc032_name"}`. `selected` и `definitions` заполняет действующий механизм подготовки. Проектные ключи имеют собственный префикс, игровые определения сохраняются под исходными ключами. Повторная публикация воспроизводит тот же состав документов. [Профиль](../../config/parser_sources.json)
2. Правило построения проектного ключа по игровому ID задаётся в конфиге ключей сервера. Сервер пакетно запрашивает русские проектные названия через `lookup`, которая также раскрывает ссылки на игровые строки. Для английского сервер запрашивает игровой `localizable_name` и при отсутствии перевода использует каталоговое `name`. Для будущего DLC без проектного перевода применяется тот же игровой путь на выбранном языке. Пропущенный или нераскрытый проектный перевод для текущих 36 считается ошибкой проверки словаря. [Правила ключей](../../src/server/config/localization_keys.json) · [Серверный поиск](../../src/server/sttv_server/localization.py)
3. Фронтенд показывает `name[language]` из серверного ответа и сортирует по отображаемому названию на текущем языке. Переключение RU/EN сохраняет игровые ID, выбранные DLC и дерево.

## Миниатюры DLC

Стенд отдаёт корректный PNG для всех 32 объявленных миниатюр. Сейчас ответ `GET /api/trees/reference/dlcs` содержит `id` и `name`, а компонент строки всегда получает `image={null}`.

Добавить к строке ответа поле `thumbnail` с относительным путём опубликованного PNG либо `null`. Сервер читает `thumbnail` из соответствующего документа `dlc_descriptors` в MongoDB и применяет то же правило пути, что загрузчик изображений. Например, для `dlc040` путь равен `dlc/dlc040_nomads/thumbnail.png`. Клиент использует настроенный базовый URL ресурсов и может показать список до первого открытия дерева. При `null` запрос изображения отсутствует. Ошибка загрузки отдельной миниатюры сохраняет название и работоспособность переключателя. [Правило загрузчика](../../src/loader/Docs/TZ_IMAGE_UPLOAD_RU.md)

## Удаление файлового режима

Убрать из боковой панели «Открыть набор БД», «Сохранить отчёт», «Открыть дерево-справочник» и прежнее размещение очистки. Удалить из рабочего фронтенда открытие каталога, файловый worker и его контроллер, экспорт отчёта, файловую ветку DLC, обращения к прежнему файловому сервису и связанные только с ними зависимости, строки, настройки и проверки. При удалении проследить импорты общих компонентов. Серверное дерево использует карточки, локализацию, измерение поля, прокрутку и отрисовку связей.

Источниками диагностики серверного режима служат журнал сервера и состояние сборки в `tree_configs`, включая длительности и причину сбоя. Удаляемый отчёт собирает диагностику локальных файлов в браузере. Сообщения об ошибках активных операций остаются в панели состояния.

## Приёмка

1. Проверить новую навигацию, выбор вкладок мышью и клавиатурой, подписи RU/EN, сохранение черновика при переходах и отсутствие запросов сборки при старте и входе в настройки.
2. Открыть справочник через меню, вернуться к нему после посещения настроек, выключить и снова включить режим. Проверить сообщение режима империи, доступность DLC и корректное отображение дерева после смены режима.
3. Применить пустой и частичный наборы DLC, отменить черновик и проверить ошибку применения. Выбранные ID должны сохраняться при смене языка и режима.
4. Для всех 36 ID проверить отдельный документ RU и полностью раскрытую проектную подпись. Проверить выдачу RU/EN для `dlc004` («Набор рас „Растеноиды“» / «Plantoids Species Pack»), `dlc001` без дескриптора и `dlc032` («Машинный век» / «The Machine Age»). Для дополнительного тестового DLC без проектной строки проверить резервное игровое название. Проверить изображение `dlc040`, отсутствующее у `dlc001` и недоступный URL.
5. На тестовых данных проверить успешную и неудачную очистку, отсутствие повторного запроса от двойного нажатия и повторное открытие после успеха. Проверить сборку фронтенда без файлового режима и доступность карточек, изображений и связей в серверном дереве.
