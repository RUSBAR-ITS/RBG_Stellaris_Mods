## Запуск и выбор файлов

Из `WEB_STTV` выполнить `npm run dev`, затем открыть `http://127.0.0.1:5173/`. При использовании подготовленного Node.js:

```powershell
$env:PATH = "$PWD/data/frontend-tools/node-v24.22.3-win-x64;$env:PATH"
npm.cmd run dev
```

Нажать «Открыть набор БД» и выбрать все **15 JSON из `data/databases/`**, собранных [этапом 12](../BACKEND_STAGE_12_RU.md). Не выбирать `reports/database_set.json`. Имена и порядок файлов произвольны: роли определяются по `dataset.kind`. Нужны версия БД 6 и один общий `set_id`.

Старт приложения и обновление страницы не читают БД и не вызывают генератор. Отмена выбора сохраняет текущий экран. Новый выбранный набор заменяет прежний; «Отмена» прекращает текущую загрузку, «Повторить» повторяет весь выбранный набор.

## Потоковое чтение

Прямой `File.text()` оказался непригоден для форматированного файла компонентов размером 831 МиБ: Chromium вернул пустую строку. Пользователь согласовал потоковую обработку, отражённую в [ТЗ](TZ_FRONTEND_STAGE_3_RU.md#согласованное-дополнение-потоковый-json).

Worker последовательно обрабатывает файлы. Первый проход получает метаданные и число документов, второй передаёт документы адаптерам по одному. UTF-8 и JSON разбираются порциями; огромная строка и полное дерево файла не сохраняются. Координаты и история раскрытия не нужны текущему UI и не загружаются в его каталоги, но остаются в исходных JSON.

Межобъектные ссылки проверяются после получения всего набора. Основной поток получает один `ready` с компактными каталогами, локализацией и диагностикой. Ошибка позднего файла не публикует частичный результат. Исходные JSON доступны только для чтения.

## Каталоги и локализация

Существующие технологии, компоненты, здания и связи сохраняются. Для 12 новых ролей добавлены `definitions` и `definitionIndex`: тип, игровой ID при наличии, `{database, pointer}` и ссылки на тексты. У терраформирования сохраняются все переходы и локализованные конечные классы; у обработчиков — все фрагменты одного имени; у событий — игровой `id` и отдельные условные описания.

Все роли используют один индекс локализации `database`. Совпадающие строки объединяют происхождения; противоречивые найденные тексты останавливают открытие. Отсутствующий перевод даёт предупреждение, а отсутствие обязательного обогащения — ошибку. Поле технологии, выбор вариантов, темы, язык и тултипы сохраняют прежнее поведение.

## Диагностика

Панель состояния показывает фазу, номер файла и локализованное имя роли при подготовке. Неверное число файлов выводится вместе с ожидаемым числом из реестра. Технический отчёт сохраняется кнопкой меню; он содержит файлы, роли, этап и адрес ошибки, когда он известен. Несовместимые версии, смешанные наборы, повторы ролей и настоящих ID блокируют открытие.

## Проверки и ограничения

Пройдены 31 контрольный тест потокового JSON и адаптеров, сборка TypeScript/Vite и 11 контрольных браузерных сценариев. Отдельно проверены чтение файла компонентов размером 831 МиБ, отмена его загрузки и повторное открытие. Ошибки позднего файла, неверное число участников, смешанные наборы, повторные ID и конфликт локализации не публикуют частичный результат.

**Полный опубликованный набор из 15 БД успешно открыт в собранном интерфейсе** на Chromium 159.0.8154.6: 11 762 739 507 байт обработаны за **264,60 с (4 минуты 25 секунд)**. Файлы переданы в обратном порядке. Отображены 679 карточек; проверены RU/EN, дневная и ночная темы, тултип и варианты «Титанов». Работал один Worker; ошибок страницы нет. Снимки ночного интерфейса и тултипа проверены визуально.

В конце браузерного теста `performance.memory` сообщил 86,4 МБ занятой памяти основного JS-потока. Это не пиковое потребление и не суммарная память браузера; память Worker отдельно не измерена. Время открытия относится к этой машине и этому набору, а не является гарантией производительности.

Дополнительно прошли две проверки реальных данных: сохранены 615 технологических связей, 720 связей улучшений объектов и 138 пар улучшений технологий; подтверждены все 60 ранее исследованных примеров для 16 технологий. Компактный результат для основного потока занимает 52 192 376 байт при сериализации в UTF-8 JSON — это размер данных, а не оценка памяти JS. В индексе остаются 214 предупреждений `missing_localization`; конфликтов найденных текстов нет. Подробности — в [отчёте каталогов](../../data/stage12/frontend_catalog_report.json).

Артефакты: [браузерный отчёт](../../data/stage12/browser_real_set.json), [ночной интерфейс](../../data/frontend-tests/real-night.png), [тултип](../../data/frontend-tests/real-tooltip.png). Размеры и время сборки БД приведены в [руководстве бэкэнда](../BACKEND_STAGE_12_RU.md#проверки).
