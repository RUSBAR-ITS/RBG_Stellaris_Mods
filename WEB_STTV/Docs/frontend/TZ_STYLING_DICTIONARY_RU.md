## Статус и назначение

Документ фиксирует структуру словаря оформления, палитры и типографику, согласованные пользователем 2026-11-16. Словарь хранится в отдельных CSS-файлах с именованными переменными, которые интерфейс использует напрямую. Реализация словаря и интерфейса продукта ещё не начата.

Основа — [концепт интерфейса](CONCEPT_RU.md#словарь-цветов-и-шрифтов) и ТЗ элементов из [справочника UI](UI_ELEMENTS_RU.md). Словарь задаёт цвета и шрифтовые параметры всех текущих элементов и их согласованных состояний.

## Два уровня переменных

Предусмотрены два уровня:

| Уровень | Назначение | Примеры |
| --- | --- | --- |
| Общие переменные | Повторно используемые значения оформления, включая фон поверхности, основной текст, границу и шрифт интерфейса | `--sttv-surface-background`, `--sttv-text-primary`, `--sttv-font-family` |
| Переменные элементов | Конкретное свойство элемента или его части с учётом состояния | `--sttv-tech-card-background-default`, `--sttv-tech-card-title-color` |

Переменная элемента может ссылаться на общую переменную. Конкретные значения и связи между переменными назначаются в словаре. Уникальное для элемента значение также задаётся в словаре.

Пример назначений внутри словаря:

```css
--sttv-tech-card-background-default: var(--sttv-surface-background);
--sttv-tech-card-title-color: var(--sttv-text-primary);
--sttv-tech-card-title-font-family: var(--sttv-font-family);
```

Пример показывает связь двух уровней; это не полный перечень переменных или готовый CSS-файл.

## Использование и именование

Элемент обращается к собственным переменным оформления. Если несколько элементов выглядят одинаково, их отдельные переменные ссылаются на общие определения. Изменение назначения одной переменной элемента позволяет изменить его независимо от остальных.

В стилях компонентов и видов цветовые литералы и шрифтовые значения не дублируются. Общие значения используются через назначения переменных элементов в словаре.

Имена пишутся на английском языке с префиксом `--sttv-` и отражают элемент, назначение свойства и, когда применимо, состояние. Например, `--sttv-tech-card-background-hover` относится к фону карточки при наведении, а `--sttv-tooltip-text-color` — к цвету текста тултипа. Окончательный перечень имён определяется при проектировании реализации.

Общие элементы «Текст» и «Иконка» получают роль оформления от использующего компонента по своим ТЗ. Так название карточки, подпись кнопки и текст тултипа используют свои переменные при повторном использовании базового элемента.

## Дневная и ночная темы

Каждая тема обеспечивает полный набор используемых значений: непосредственно или через общие определения. Для каждой используемой переменной должна существовать определённая цепочка назначений до конкретного значения в обеих темах.

Переключение темы меняет назначения для всего интерфейса. Компоненты и виды продолжают использовать прежние имена переменных; собственные цветовые значения для переключения темы в них не вводятся.

Совпадающие значения могут ссылаться на общие определения. Повторять одинаковые значения в файлах обеих тем не требуется, если общая часть словаря обеспечивает их доступность в каждой теме.

## Согласованная палитра

Основа оформления — нейтральные серые фоны и приглушённый зелёный акцент для наведения, выбора и фокуса. Области науки на первом этапе различаются заголовками; отдельные цветовые палитры для них не вводятся.

| Назначение | Дневная тема | Ночная тема |
| --- | --- | --- |
| Фон поля технологий | `#F3F5F7` | `#151B20` |
| Фон панели меню | `#E8EDF0` | `#1C252C` |
| Фон карточки, тултипа и обычного элемента управления | `#FFFFFF` | `#263139` |
| Фон при наведении | `#E6F2EE` | `#303F47` |
| Фон при нажатии | `#D3E8DF` | `#374C52` |
| Основной текст | `#202A32` | `#E6EDF2` |
| Вторичный текст | `#53616D` | `#ADBCC6` |
| Обычная граница | `#73828E` | `#6F828E` |
| Акцент выбора и фокуса | `#176B50` | `#79CEAA` |

Значения назначаются общим определениям словаря. Собственные переменные элементов ссылаются на них по своей роли и состоянию. При наведении карточка или элемент управления использует фон наведения и акцентную границу; при нажатии элемент управления использует соответствующий фон. Фокус обозначается акцентом. Состояния применяются только там, где они предусмотрены ТЗ элемента.

Для основного, вторичного и акцентного текста рассчитан контраст на пяти фонах: поле, меню, обычная поверхность, наведение и нажатие. Минимум среди этих сочетаний составляет **4,97:1** в дневной и **4,65:1** в ночной теме. Это расчёт для перечисленных цветов; фактическое отображение интерфейса проверяется после реализации. Акцент предназначен для выделения и фокуса, а его использование как заливки с текстом поверх потребует отдельного назначения цвета текста.

## Состояния элементов

Переменные создаются только для состояний, предусмотренных ТЗ конкретного элемента. Например, у кнопки учитываются наведение и нажатие, а у ползунка — перетаскивание. Наличие состояния у одного элемента не означает, что оно должно добавляться остальным.

Если значения разных элементов или состояний совпадают, соответствующие переменные явно ссылаются на общее определение. Это сохраняет однозначность назначений и возможность изменить одно состояние отдельно.

Компонент выбирает переменную для своего состояния; словарь определяет её значение. Оформление вложенных текста и иконки следует состоянию использующего компонента по их ТЗ. Смена состояния сохраняет геометрию в случаях, где это требуется ТЗ элемента.

## Шрифты и текстовые роли

Для каждой текстовой роли через словарь задаются:

- Семейство шрифта.
- Размер шрифта.
- Насыщенность шрифта.
- Межстрочный интервал.

Цвет текста задаётся отдельной цветовой переменной соответствующей роли. Для названия технологии, описания, подписи настройки и других применений предусмотрены свои назначения по [ТЗ элемента «Текст»](elements/TZ_TEXT_RU.md#оформление-и-роли).

На первом этапе типографика одинакова для дневной и ночной темы: семейство, размер, насыщенность и межстрочный интервал одной роли сохраняются при переключении темы. Общие определения позволяют переиспользовать эти значения.

Выбран шрифт **Inter** для обеих локализаций. Поддержка кириллицы и латиницы подтверждена [данными семейства Google Fonts](https://github.com/google/fonts/blob/main/ofl/inter/METADATA.pb).

| Текстовая роль | Размер, CSS px | Межстрочный интервал, CSS px | Насыщенность |
| --- | --- | --- | --- |
| Название технологии в карточке | 15 | 20 | 500 |
| Описание в тултипе | 15 | 22 | 400 |
| Название технологии в тултипе | 16 | 22 | 600 |
| Заголовок области науки | 18 | 24 | 600 |
| Заголовок уровня | 13 | 18 | 500 |
| Текст кнопки и элемента выбора | 14 | 20 | 500 |

Размеры приведены в CSS-пикселях при обычном масштабе интерфейса. Значения хранятся в словаре и переиспользуются через переменные текстовых ролей. Типографика прочих ролей назначается при составлении полного перечня переменных.

Файлы Inter включаются в portable-сборку и загружаются локально: установка шрифта в Windows и доступ к интернету во время работы приложения не требуются. Вместе со шрифтом поставляются уведомление об авторских правах и текст [лицензии SIL Open Font License 1.1](https://github.com/rsms/inter/blob/master/LICENSE.txt). Конкретные файлы шрифта, их версия и пути подключения определяются при проектировании реализации.

## Организация файлов

Словарь разделяется на небольшие CSS-файлы по назначению:

| Часть | Содержимое |
| --- | --- |
| Общие определения | Переиспользуемые значения, в том числе общая для обеих тем типографика |
| Значения тем | Назначения для дневной и ночной темы |
| Назначения элементов | Переменные конкретных элементов и состояний, их ссылки на общие определения или собственные значения |

Назначения элементов распределяются по отдельным небольшим файлам. Составные компоненты и виды используют переменные своих элементов, сохраняя разделение словаря и компоновки интерфейса.

Точные пути, имена файлов, способ их подключения и механизм выбора активной темы будут определены при проектировании реализации. На этом этапе фиксируются CSS-формат и разделение ответственности между частями словаря.

## Критерии приёмки

Проверки выполняются после реализации:

- Словарь представлен отдельными CSS-файлами; общие определения, значения тем и назначения элементов разделены.
- Компоненты и виды используют собственные переменные элементов для цветов и шрифтов, без повторения конкретных значений в их стилях.
- Имена используют префикс `--sttv-` и однозначно обозначают элемент, свойство и применимое состояние.
- В обеих темах каждая используемая переменная разрешается в конкретное значение; отсутствующие ссылки и циклические назначения не допускаются.
- Изменение общей переменной отражается во всех ссылающихся на неё назначениях. Изменение назначения отдельного элемента не меняет независимые назначения других элементов.
- Все согласованные состояния используемых элементов имеют необходимые назначения; одинаковые значения переиспользуются через явные ссылки на общие определения.
- Переключение темы обновляет весь интерфейс, включая открытые списки и тултипы, при сохранении имён используемых компонентами переменных.
- Для каждой текстовой роли определены цвет, семейство, размер, насыщенность и межстрочный интервал; типографика одной роли одинакова в обеих темах.
- Значения палитр и перечисленных текстовых ролей соответствуют согласованным таблицам этого документа.
- Inter загружается из поставки приложения без установки в системе и обращения к внешнему сервису; кириллица и латиница отображаются в интерфейсных строках, названиях технологий и описаниях. В поставке присутствуют уведомление об авторских правах и лицензия шрифта.
- Смена состояния элемента сохраняет геометрию в соответствии с его ТЗ.

## Детали последующей реализации

Для [панели состояния](elements/TZ_STATUS_PANEL_RU.md) также определяются собственные переменные фона, границы, цвета сообщения и шрифтовых параметров. Общий элемент «Текст» получает роль панели. Назначения для обеих тем и необходимость отличающихся значений по состояниям входят в последующее проектирование; новые конкретные цвета и размеры шрифта этим дополнением не задаются.

По [ТЗ структуры фронтенда](TZ_STRUCTURE_RU.md) словарь и общие стили размещаются в `src/frontend/styles/`, стили компонентов — рядом с компонентами, локальные шрифты — в `src/frontend/assets/`. Предстоит определить полный перечень переменных и их назначений для текущих элементов на основе согласованных палитр и типографики. Точные файлы CSS и порядок подключения, файлы и версия Inter, обозначение активной темы и приоритеты одновременно действующих состояний также требуют проектирования.

Размеры карточек, ширина панелей, отступы и другие параметры компоновки определяются соответствующими ТЗ и настройками реализации. Настоящий документ посвящён словарю цветов и шрифтов.
