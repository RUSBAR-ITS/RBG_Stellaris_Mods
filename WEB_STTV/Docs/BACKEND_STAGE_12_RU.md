## Запуск

Реализация [этапа 12](TZ_BACKEND_STAGE_12_RU.md). Из каталога `WEB_STTV`:

```powershell
$env:PYTHONPATH = 'src/backend'
& ./data/.venv/Scripts/python.exe -B -m sttv.database_sets
```

При установленном Python с зависимостями проекта вместо пути к виртуальному окружению можно использовать `python`. Аргументы `--variables` и `--config` выбирают настройки. Запуск явный; фронтенд генератор не вызывает. Старый набор версии 5 нужно перестроить.

## Настройки и формат

- `config/datasets.json` — единый реестр 15 ролей, каталогов, корневых типов и идентичности. Используется бэкэндом, генератором схем и фронтендом.
- `global_variables.json` — корни источников, относительные каталоги и `WORK_DIR`.
- `config/backend.json` — источники и выходы каждого участника, общие настройки парсера.
- `config/enrichment/localization.json` — языки, приоритеты и ссылки на отдельные правила `config/enrichment/targets/<kind>.json`.

БД имеют формат `sttv.parse_database`, версию `6`, метку `{kind, set_id}`. Форматирование: UTF-8 без BOM, Unicode, LF, два пробела, завершающий перевод строки. Общий `set_id` вычисляется из канонического содержимого всех участников; форматированные файлы сохраняют полное дерево и его происхождение.

Состав: `technologies`, `components`, `buildings`, `megastructures`, `ship_sizes`, `starbase_levels`, `starbase_modules`, `starbase_buildings`, `terraform`, `deposits`, `pop_jobs`, `economic_categories`, `scripted_actions`, `on_actions`, `events`.

## Объекты и локализация

Названия и описания RU/EN находятся в `enrichments.localization`. У цели могут быть оба поля, только одно или ни одного. Русские приоритеты прежние: `RU_LOC_TIER_1` → `RU_LOC_TIER_2` → `RU_LOC_TIER_3`; английский — `EN_LOC_TIER_1`. Статические ссылки раскрываются, динамические подстановки сохраняются.

Именованные определения сохраняют ID; у события это прямое поле `id`, а корневой ключ обозначает тип события. Повторы настоящих ID внутри роли диагностируются. Все условные описания событий сохраняются отдельно. Скрытое событие может не иметь локализации.

Повторные `terraform_link` сохраняются по адресам, без выдуманного игрового ID; локализуются `from` и `to`. Фрагменты `on_actions` с одинаковым именем не объединяются. Служебные определения без текстовых целей допустимы. Игровые условия не вычисляются.

## Исключения импорта

`config/parser/source_exceptions.json` задаёт три узких правила для четырёх файлов. Исправляются лишний разделитель конкретной ссылки script value, пропущенный `RELIC` через переданный `SELECTED_RELIC` и согласованное временное `RANDOM = 0`. Условия, происхождение и журналирование описаны в [дополнении](SOURCE_IMPORT_EXCEPTIONS_RU.md).

Имена параметров сопоставляются без учёта регистра. Структурное раскрытие `effect = no` сохраняет исходный аргумент в истории; оно не выполняет эффект и не утверждает поведение движка. Составная статическая ссылка разрешается, если все её контексты находят одно объявление; разные локальные объявления по-прежнему дают ошибку.

## Публикация и отчёты

Результаты находятся в `WORK_DIR/databases/<kind>.json`, отчёты — в `WORK_DIR/reports/`. Для каждого участника сохраняются отчёты сборки и локализации; `database_set.json` — сводный отчёт, не шестнадцатая БД. Он содержит время, размеры, числа документов, объектов и текстовых целей, предупреждения, хеши входов и результат публикации.

Координатор готовит участников последовательно и перед публикацией проверяет неизменность источников. Ошибка подготовки оставляет прежние БД. Каждый файл заменяется атомарно; весь набор заменяется последовательно. Сбой между заменами виден в отчёте, а смешанные `set_id` отклоняются фронтендом.

## Проверки

Полная сборка 2026-11-18 успешна: 450 документов, 15 599 определений и 22 345 целей локализации; ошибок и пропущенных документов нет. Все семь ранее проблемных файлов вошли в результат. Проверена неизменность 1625 входных файлов. Пройдены 203 теста Python, включая повторные определения, текстовые цели, исключения, воспроизводимость, ошибку последнего участника и частичную публикацию; 18 схем совпадают с результатом генератора.

Исключения применены 40 раз: `RELIC` — 30, временный `RANDOM = 0` — 9, лишний разделитель — 1. Кроме этих зарегистрированных преобразований, отчёты содержат 50 предупреждений о неиспользованных аргументах inline-вызовов. Локализация содержит 218 записей об отсутствующих полях и 52 записи о нераскрытых ссылках, суммарно по двум языкам и всем целям. Это предупреждения источников; отсутствующие строки не сочиняются, неразрешённые ссылки сохраняются.

Набор занимает **11 762 739 507 байт (10,95 ГиБ)**; `events.json` — **9 386 721 787 байт (8,74 ГиБ)**. Полная сборка заняла **5490,835 с (91,5 минуты)**. Проверки схемы большого дерева событий и сохранение полного происхождения делают этот этап дорогим по времени и памяти; оптимизация этих затрат отдельно не проводилась.
